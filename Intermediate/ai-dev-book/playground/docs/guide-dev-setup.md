# Guide: setting up your laptop

## Accounts
Ask your manager for a GitHub invite and an SSO account. You need the VPN for staging; production access needs an approved ticket.

## Tools
Install JDK 25, Python 3.13, Docker Desktop and the `deployctl` CLI. Run `make bootstrap` in the platform repo; it installs the pre-commit hooks and checks the versions.

## First week
Pair with your onboarding buddy, ship one small change to production, and read the incident severity guide.
