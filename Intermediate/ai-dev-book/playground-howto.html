Using the Playground

The book comes with a playground repository, coderhop-learning/ai-book-playground: the llmkit toolkit, the DocsPilot sample company, and every module the chapters build. This page shows how to set up Python, how to run the examples with or without an API key, and how the book's own examples are checked.

You will learn

  • What to install, and how to create a virtual environment.
  • What's in the playground and what llmkit gives you.
  • How to run examples offline against the mock Messages API, or against Claude with a key.
  • How every example in the book was verified.
  • Fixes for common setup problems.

Each module is exactly the code shown in its chapter, so you can import it from later chapters and exercises, or read the finished version when you're stuck. 4. Running examples offline: the mock server

Examples written for the real SDK (anthropic.Anthropic()) need a server. Start the mock in one terminal; it prints the environment variables to set in another:

Every SDK and framework in the book reads ANTHROPIC_BASE_URL, so the code is unchanged. You can also start a server inside a script, as several chapters do:

What the mock does, so its answers don't surprise you:

  • It checks requests like the real API for the rules this book teaches: unknown models (404), missing max_tokens, sampling parameters, assistant prefill, forced tool_choice on the newest models, tool results without a matching tool call (400), API keys starting with bad (401).
  • Its answers are honest placeholders: "(mock reply) You said: …", a minimal object that matches your JSON Schema, a tool call when a tool's name or description matches the question, a citation quoting the best-matching document.
  • It supports streaming (SSE), token counting, prompt caching (prefixes of 1,024+ toy tokens), the Batches API, rate-limit headers, and injected failures: mock_api(fail_first=2, fail_status=529).

5. Running against Claude

Create a key in the Claude Console, unset ANTHROPIC_BASE_URL and export the key. The same examples now call Claude; only the wording of the answers (and the token counts) changes:

Real calls cost money. The eval and batch examples make many calls. Start with small sets, read usage, and set a spend limit on your key.

6. How the book's examples were checked

A script extracts every code block from every page and runs it in a fresh folder that contains a copy of the playground, with the mock server running and ANTHROPIC_BASE_URL pointing at it. Python blocks run as scripts; the output block after each one must match what the script really printed. Blocks marked "output (mock server)" show the mock's answers; with a real key you'll see Claude's.

Java snippets (in ☕ boxes) are for reading: they show the same idea with java.net.http, the Anthropic Java SDK, Spring AI or LangChain4j, and are not run.
