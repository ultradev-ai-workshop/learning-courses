🤖 AI for Developers Study Book

Building with LLMs, from a developer's point of view. You already know how to build reliable services; this book teaches you to build reliable services where one dependency is a probabilistic text engine: with contracts, tests, retries, budgets, observability and threat models.

How to use this book

  • Read in order. 15 chapters in five parts: Foundations (how LLMs work, prompts, APIs), Building Blocks (structured output, tools, embeddings, RAG), Agents & Integration (agents, MCP), Shipping AI Features (evals, production, security) and At Work & Beyond, ending with the DocsPilot project.
  • Python first, Java alongside. Every example is Python and runs. The ☕ boxes connect each idea to Java and backend practice, with Java versions of the key code (raw HTTP, the Anthropic Java SDK, Spring AI, LangChain4j).
  • Raw API first, frameworks later. Chapters 3–5 build clients, tool loops and structured output by hand, so you know what every framework does for you. The appendices then cover LangChain, LangGraph, LlamaIndex, Pydantic AI, DSPy and the rest of the landscape.
  • Look for the 🧠 boxes. Every hard idea (tokens, injection, RAG, agents, evals) comes with a real-world analogy.
  • Run the examples without a key. All examples run offline: llmkit provides a toy tokenizer, a tiny language model, a small embedding model, FakeAnthropic, and a local mock of the Messages API that the real anthropic, openai, LangChain, Pydantic AI and DSPy clients talk to unchanged. Every output in the book was produced by running it. See Using the Playground.
  • Do the exercises. Each chapter and appendix has 10 exercises marked 🟢 easy, 🟡 medium or 🔴 hard, with hidden solutions.
  • Questions before you start? The FAQ covers API keys (you don't need one), building agents, prerequisites and further reading.
  • Test yourself. The Final Assessment draws 50 random questions from a pool of 1000, with a 50-minute timer, and scores you per chapter.

📝 Setup: clone the playground repository, coderhop-learning/ai-book-playground, with git clone https://github.com/coderhop-learning/ai-book-playground.git. Then, with Python 3.12 or newer, run pip install anthropic pydantic numpy rank-bm25 mcp inside it (and the framework packages for the appendices). With an ANTHROPIC_API_KEY the examples call Claude; without one, start the mock server as described in Using the Playground.

💡 Facts that change often. Model IDs, prices, SDK method names and spec revisions in this edition are current as of November 2026 (models claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5; MCP 2026-07-28). Each chapter ends with the official pages to check before you depend on a detail.
