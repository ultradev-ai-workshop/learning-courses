🟩 Node.js Study Book

A chapter-by-chapter course through Node.js Learn, from your first script to a tested, production-ready HTTP API. It's written for developers who know JavaScript (the JavaScript Study Book level) and want to understand how Node really works: the event loop, streams, servers and the tools around them.

How to use this book

  • Read in order. The 16 chapters follow the Node.js Learn sections (Getting Started, Command Line, Modules, Asynchronous Work, Files, HTTP, Concurrency, Test Runner, Diagnostics…), grouped into six parts and ordered from basic to intermediate.
  • Look for the 🧠 boxes. Every hard idea — the event loop, backpressure, the thread pool, streams — comes with a real-world analogy, and 🌐/☕ boxes connect it to what you already know from browser JavaScript and Java.
  • Type the examples. Every example was run on Node 26 and its output checked. $ blocks are terminal sessions, > blocks are REPL sessions, file blocks are ES modules. Use the Copy button.
  • Do the exercises. Each chapter has 10 exercises marked 🟢 easy, 🟡 medium or 🔴 hard, with hidden solutions. Playground exercises grow towards the Chapter 16 project.
  • Test yourself. The Final Assessment draws 50 random questions from a pool of 1000, and scores you per chapter.
  • Practise beyond the book. The 🧩 Problem Set has 100 language-neutral problems with exact tests — solve them as Node scripts.

💡 New to the JavaScript language itself? Do the JavaScript Study Book first (at least Chapters 1–12). Coming from browser code or libraries like axios, chalk or Mocha? Appendix B maps them to built-in Node features. Want types? Appendix A runs TypeScript natively. First time here? Start with Using the Playground.

📝 Setup: install Node 26 (Current) or Node 24 LTS and check it with node --version, then clone the practice project, coder-hop/nodejs-book-playground, with git clone https://github.com/coder-hop/nodejs-book-playground.git playground. Node 24 runs nearly every example; differences are marked with badges like Node 26.
