Using the Playground

The playground/ folder next to this book is your workspace. Exercises marked playground ask you to create files there, and together they grow into the Chapter 16 project. This page shows how to set it up, run files, use watch mode and the REPL, run tests, and fix the most common problems.

Any editor works; VS Code has excellent Node support (debugging, a JavaScript Debug Terminal, test integration).

2. The playground folder

"type": "module" makes every .js file an ES module, so import/export and top-level await work everywhere, as in the book. "private": true prevents accidental publishing.

3. Running code

  • node --watch hello.js re-runs the file every time you save it (or anything it imports). Stop with Ctrl+C.
  • node --env-file=.env app.js loads environment variables from a file (Chapter 2).
  • node -p "expression" prints the value of a one-liner.
  • Servers keep running until you press Ctrl+C; the book's examples close themselves so they can be checked automatically.
