How to learn here: overview first, depth second, then practise

Every course is built the same way, around how memory actually works.

Why new things feel hardYour working memory is tinyIt holds only a handful of new things at once. Dump every detail on day one and most of it slips away; new ideas stick when they attach to a map you already have.
So learn in two passesBig picture first, details secondKnowing the names and main ideas first frees your memory for the details. Learning research calls this pre-training.
Then make it stickCome back. Recall. Practise.Without review, new memories fade fast (the forgetting curve). Each spaced review slows the fade, and recalling an answer beats re-reading it.
  1. Step 1

    Watch the overview

    Short videos on the coderhop YouTube channel, one per chapter: just the core ideas, to build the map.

    Pass 1 · the map
  2. 📖
    Step 2

    Study each concept

    Come back to the course and read the same chapter in depth, curated from the official docs. Run every example yourself.

    Pass 2 · the details
  3. 🧪
    Step 3

    Solve the exercises

    Every chapter ends with 10 exercises, from easy to hard. Do the playground ones in the course's git repo: clone it, run it, break it, fix it.

    Practise
  4. ✅
    Step 4

    Take the assessment

    50 random questions from a pool of 1000, timed, with a score per chapter. Recall beats re-reading; revisit the chapters you scored lowest.

    Recall
  5. 🔗
    Step 5

    Go further

    When you need more, follow each chapter's links to the official docs and the course's further reading.

    If needed

Come back and review. Re-watch a chapter's video or retake the assessment a few days later. Each spaced review flattens the forgetting curve: the dashed line is no review, the solid line is reviewing.
