A chapter-by-chapter course

⚛️ React Beginner Book

Learn React from zero, in plain language, following the structure of the official react.dev/learn docs. Every chapter has small examples you can type into your own project.

How to use this book
  • Read the chapters in order. Each one builds on the one before. If your JavaScript is rusty, start with Appendix A: JavaScript Refresher.
  • Type the examples yourself in sample-test-react/src/App.jsx (run npm run dev). Typing beats copy-pasting for learning.
  • Each chapter has a "More examples" section and 10 exercises (150 in total), labelled 🟢 easy, 🟡 medium or 🔴 hard. Try each one before you open its solution.
  • Each chapter ends with links to the matching official docs pages for deeper reading.
