Adding an event handler

An event handler is a function that runs in response to something the user does. You write it, then pass it to a JSX element:

  1. Define a function inside the component. By convention its name starts with handle plus the event: handleClick, handleMouseEnter, handleSubmit.
  2. Pass it as a prop: onClick={handleClick}.

You can also write it inline, which is handy for short handlers:

⚠️ Pass the function, don't call it

✅ Passing a function🔴 Calling a function
onClick={handleClick}onClick={handleClick()}
onClick={() => alert('hi')}onClick={alert('hi')}

With parentheses, the function runs immediately, while rendering, not on click. And if it updates state, that triggers another render, which calls it again: an infinite loop ("Too many re-renders").

The rule: onClick needs a function to call later. To pass an argument, wrap the call in an arrow function: onClick={() => deleteItem(id)}.

Naming your own event props

For your own components, name event props on + something meaningful to your app, not just to the browser:

Convention Props are named onSomething; the functions you pass are named handleSomething. For example: <Toolbar onPlayMovie={handlePlayMovie} />.

Recap

  • Handle events by passing a function: onClick={handleClick} (no parentheses!).
  • Handlers are defined inside components, so they can read props.
  • Pass handlers down as props named onSomething. This is how children talk to parents.
  • Events bubble up. e.stopPropagation() stops that; e.preventDefault() stops the browser's default action.
