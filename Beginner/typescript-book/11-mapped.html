Mapped & Template Literal Types

A mapped type builds a new object type by looping over keys, like Array.map but for properties. A template literal type builds string types the way template strings build strings. Together they describe APIs such as onChange handlers, getters and setters, or "GET /books" routes. This chapter follows the Handbook pages Mapped Types and Template Literal Types.

You will learn

  • The syntax { [K in Keys]: Type }.
  • Adding and removing readonly and ? with +/- modifiers.
  • Key remapping with as, including filtering keys out.
  • Template literal types, and how they combine with unions.
  • The intrinsic string types Uppercase, Lowercase, Capitalize, Uncapitalize.

A mapped type over keyof T keeps each property's original modifiers unless you change them. That's called a homomorphic mapped type: it has the same "shape" as T.

When you write "ageChanged", TypeScript infers K = "age" from the template, so newAge is a number. The implementation uses a Proxy and a few casts; callers get the precise types.

☕ Java / C#: nothing like this exists in Java's or C#'s type systems. A Java developer would generate code (annotation processors, Lombok's getters) or use reflection. In TypeScript, the "generated" API lives purely in the types, with zero runtime cost, and the editor autocompletes getName and "ageChanged" as if they were written by hand.

Recap

  • { [K in Keys]: T } creates one property per key; over keyof T it keeps modifiers (homomorphic).
  • +/- add or remove readonly and ?: that's how Partial, Required, Readonly work.
  • as renames keys; mapping a key to never removes it.
  • Template literal types build string types; unions in placeholders produce every combination.
  • `b${number}` and `${string}Changed` are patterns that also drive inference.
  • Uppercase, Lowercase, Capitalize, Uncapitalize transform string literals.

Exercise 9 🔴 hard explain

Why do you need string & K (or keyof T & string) before Capitalize in a key remapping?

Show solution

keyof T is string | number | symbol in general, and Capitalize requires a string. Intersecting with string keeps only the string keys (number and symbol keys become never and are dropped), so the template type is valid.
