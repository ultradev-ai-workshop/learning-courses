🟦 TypeScript Study Book

A chapter-by-chapter course through the official TypeScript documentation: the Handbook, its reference pages, declaration files and project configuration. It's written for developers who already know JavaScript, with ☕ boxes that compare every idea with Java and C#, and it ends the way the TypeScript team recommends adopting the language: by migrating a real JavaScript project to strict TypeScript.

How to use this book

  • Read in order. The 19 chapters follow the Handbook, grouped into five parts. Each uses only ideas from earlier chapters, or says where an idea is explained.
  • Read the errors. Most examples show what the compiler says, in the exact format tsc prints it: file.ts(line,col): error TSxxxx: …. Learning to read these is half of learning TypeScript.
  • Type the examples. Every example was compiled with TypeScript 7.0.2 in strict mode and run with Node, and every output and error on these pages is the real one. Use the Copy button, or paste into the online Playground.
  • Coming from Java or C#? Look for the ☕ boxes, and keep Appendix A open: it maps every Java/C# concept to TypeScript. 🧠 boxes give an everyday analogy for each hard idea.
  • Do the exercises. Each chapter has 10 exercises marked 🟢 easy, 🟡 medium or 🔴 hard, with hidden solutions. Playground exercises build the pieces of the Chapter 19 capstone.
  • Test yourself. The Final Assessment draws 50 random questions from a pool of 1000 and scores you per chapter.
  • Questions? The FAQ answers "why TypeScript if I know JavaScript?" and "what should I focus on?"; the Glossary defines every term.

💡 New to JavaScript itself? The Handbook assumes you know JavaScript. Work through the JavaScript Study Book first (at least its first 12 chapters), then come back. Already comfortable? Start with Using the Playground and Chapter 1.

⚛️ Next step: the React Beginner Book and the Node.js Study Book both get easier with types: typed props and state, typed API responses, typed configuration.

📝 Setup: install Node 22 or newer (node --version), then clone the practice project, coderhop-learning/typescript-playground, with git clone https://github.com/coderhop-learning/typescript-playground.git, and run npm install inside it. That installs the same compiler this book uses, TypeScript 7.0.2.

⚠️ Facts that change. TypeScript releases a new minor version about every three months. Version-specific details (TypeScript 7's defaults, which tools still need TypeScript 6, when Node strips types by default) were checked in November 2026. Appendix B lists them; check the TypeScript blog for newer releases.
