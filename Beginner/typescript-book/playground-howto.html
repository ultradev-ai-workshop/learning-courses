Using the TypeScript Playground

The playground is a ready-made TypeScript project for practising: one starter file per playground exercise, the JavaScript app you'll migrate in the capstone, and the finished reference. This page shows how to set it up once and how to work in it every day. You can also try any example in the official online Playground, with no install at all.

You will learn

  • What the playground contains.
  • How to install Node, clone the project and install TypeScript.
  • The everyday loop: edit, check, run, test.
  • How to use the official online Playground alongside it.
  • How to fix the most common problems.

What is the playground?

A small Node + TypeScript project, published on GitHub as coderhop-learning/typescript-playground:

One-time setup

1. Install Node.js 22 or newer

Any Node 22+ works. Get it from nodejs.org or a version manager such as fnm or nvm. From Node 22.18 and 23.6, Node can also run .ts files directly (Appendix B), but the playground uses tsc, so that every run is type-checked.

2. Clone and install

npm install installs the pinned compiler (typescript@7.0.2) and Node's types into node_modules/. Nothing is installed globally.

3. Check it works

No output after the script name means no errors.

4. Open it in an editor

Open the typescript-playground folder (not a subfolder) in VS Code or another editor with TypeScript support. In VS Code, run TypeScript: Select TypeScript Version → Use Workspace Version once, so the editor uses the same 7.0.2 compiler as npm run check.

The everyday loop

  1. Read the exercise in the book. Playground exercises name their file, e.g. exercises/ch05/fees.ts.
  2. Edit the starter file. Watch the red squiggles in the editor: they're the same errors tsc reports.
  3. Check with npm run check (all exercises), or keep npx tsc --noEmit --watch running in a terminal.
  4. Run one exercise: npm run ex -- exercises/ch05/fees.ts. It compiles everything to dist/ and runs the file's JavaScript. If there are type errors, it shows them and runs anyway, so you can see what JavaScript would do (Chapter 2).
  5. Compare with the book's Show solution, and for the capstone pieces, with reference/src/.

The official online Playground

At typescriptlang.org/play you can paste any example from this book and see:

  • errors as you type (hover them for details),
  • the emitted JavaScript (.JS tab) and declarations (.D.TS tab),
  • the effect of compiler options (TS Config menu), and different TypeScript versions.

Use it to experiment with a single idea; use the local playground for exercises that span files and for the capstone.

🧠 Analogy: a whiteboard and a workshop. The online Playground is a whiteboard: quick sketches, easy to share, wiped clean tomorrow. The local playground is your workshop: real tools, saved work, and projects that grow over many sessions.

Troubleshooting

SymptomCause and fix
tsc: command not foundRun npm install first, then use npx tsc or the npm scripts (they find the local compiler).
Cannot find name 'console' or 'process'@types/node isn't installed or "types": ["node"] is missing from the tsconfig.json you're using.
TS2835 "Relative import paths need explicit file extensions"Write ./fees.js, not ./fees, when importing fees.ts (Chapter 15).
TS1484 "… is a type and must be imported using a type-only import"verbatimModuleSyntax is on: write import { type Book } from ….
TS5112 "tsconfig.json is present but will not be loaded…"You ran tsc file.ts in a folder with a config. Run tsc or npm run check instead (or add --ignoreConfig).
The editor shows different errors from npm run checkThe editor uses another TypeScript version or another tsconfig.json. Select the workspace version, and open the playground's root folder.
npm run ex says "Cannot find module …/dist/…"Pass the path of a .ts file under exercises/, e.g. npm run ex -- exercises/ch01/hello.ts.
Node prints ExperimentalWarning: Type Stripping…You ran a .ts file with plain node on an older Node 22. Use npm run ex, or upgrade Node.
The reference or capstone-start folder doesn't existYou downloaded only part of the repository. Clone typescript-playground again.

Recap

  • Clone coderhop-learning/typescript-playground, run npm install, then npm run check.
  • Edit an exercise file, check it, run it with npm run ex -- <file>, compare with the solution.
  • Use the online Playground for quick experiments and to see emitted JavaScript.
  • The playground exercises build towards the Chapter 19 capstone in reference/.
