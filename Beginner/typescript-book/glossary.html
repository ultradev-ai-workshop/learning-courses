Reference

Glossary

The TypeScript terms used in this book, in plain words, each with the chapter where it's explained.

any
A type that turns checking off for a value and everything derived from it. Use rarely; prefer unknown. Ch. 3
Annotation
: Type written after a name to state its type explicitly. Ch. 2
Type assertion
value as Type: tells the checker to treat a value as a type. Unchecked; not a conversion. Ch. 3
Assertion function
A function returning asserts x is T: if it returns, x is a T. Ch. 4
Branded type
A primitive type made incompatible with others by intersecting it with a fake property, e.g. string & { __brand: "BookId" }. Ch. 14
Control flow analysis
How TypeScript tracks a variable's narrowed type through ifs, returns and assignments. Ch. 4
Composite project
A project with composite: true that other projects can reference; built with tsc -b. Ch. 18
Conditional type
A extends B ? X : Y: a type chosen by assignability. Ch. 10
Contextual typing
Inferring a type from where an expression is used, e.g. a callback's parameters. Ch. 3
Contravariance
The "reverse" rule for function parameters: a function accepting more can replace one accepting less. Ch. 14
Declaration file (.d.ts)
A file with only type information describing JavaScript that exists elsewhere. Ch. 17
Declaration merging
Combining several declarations with the same name (e.g. two interfaces) into one. Ch. 15
Decorator
A function applied with @name to a class or member at definition time, able to wrap or replace it. Ch. 16
DefinitelyTyped
The community repository of types for JavaScript packages, published as @types/*. Ch. 17
Discriminated union
A union whose members share a literal property (the discriminant, e.g. kind) used to tell them apart. Ch. 4
Distributive conditional type
A conditional type over a bare type parameter that is applied to each union member separately. Ch. 10
Downleveling
Rewriting newer JavaScript syntax for an older target. Ch. 2
Emit
The JavaScript (and .d.ts, source maps) that tsc writes. Independent of type errors unless noEmitOnError. Ch. 2
enum
A named set of constants that compiles to a runtime object. Not erasable. Ch. 13
Erasable syntax
TypeScript syntax that can be deleted to get valid JavaScript; erasableSyntaxOnly enforces it. Ch. 13
Type erasure
Types are removed by the compiler and don't exist at runtime. Ch. 1
Excess property check
The error for unknown properties in a fresh object literal. Ch. 6
Generic
A function, type or class with type parameters, e.g. Box<T>. Ch. 8
Index signature
[key: string]: T: describes an object used as a dictionary. Ch. 6
Indexed access type
T["prop"] or T[number]: the type of a property or element. Ch. 9
infer
Declares a type variable inside a conditional type's extends clause, filled from the matched type. Ch. 10
Type inference
TypeScript working out a type from values and context, without an annotation. Ch. 14
interface
A named object shape; can be extended and merged. Ch. 3
Intersection type
A & B: a value that is both A and B. Ch. 6
keyof
The union of a type's property names. Ch. 9
Literal type
A type with exactly one value, such as "overdue" or 42. Ch. 3
Mapped type
{ [K in Keys]: T }: an object type built by looping over keys. Ch. 11
Mixin
A function that takes a class and returns a subclass with extra members. Ch. 16
Module resolution
How the compiler finds the file behind an import path (nodenext, bundler). Ch. 15
Narrowing
Refining a wide type to a specific one with a runtime check. Ch. 4
never
The type with no values: impossible branches, functions that never return. Ch. 4
Nominal typing
Compatibility by declared name (Java, C#). TypeScript is structural, except for classes with private members and brands. Ch. 14
Overload
One of several call signatures listed above a single function implementation. Ch. 5
Parameter property
A constructor parameter with a modifier (private x: T) that also declares a field. Ch. 7
Type predicate
A return type x is T that makes a function a custom type guard. Ch. 4
Project references
Links between tsconfig projects for ordered, incremental builds. Ch. 18
satisfies
Checks a value against a type without changing the value's inferred type. Ch. 14
strict
The option family that enables the strongest checks; on by default in TS 7. Ch. 18
Structural typing
Compatibility by shape: a value fits a type if it has the required members. Ch. 1
Template literal type
A string type built with backticks, e.g. `on${Capitalize<E>}`. Ch. 11
tsconfig.json
The file that marks a TypeScript project and holds its compiler options. Ch. 18
Tuple
An array type with a fixed length and a type per position. Ch. 6
Type alias
type Name = …: a name for any type. Ch. 3
Type stripping
Running TypeScript by deleting the types without checking them (Node 22.18+/23.6+, esbuild). App. B
Union type
A | B: a value that is one of several types. Ch. 3
unknown
The type of any value, usable only after narrowing. The safe counterpart of any. Ch. 4
Utility type
A built-in generic type such as Partial, Pick, Omit, Record, ReturnType. Ch. 12
verbatimModuleSyntax
An option requiring import type for type-only imports, so imports are emitted exactly as written. Ch. 15
void
The return type of a function whose result shouldn't be used. Ch. 5
Widening
Turning a literal type into its general type ("a" → string) when stored in a mutable place. Ch. 14
