Backgrounds, Borders & Effects

This chapter covers the docs' Backgrounds, Borders, Effects and Filters groups: gradients, background images, borders and dividers, rounded corners, outlines and rings, shadows, opacity, blur and masks. These are the utilities that give an interface depth and polish. Because they're visual, most examples come with a screenshot.

You will learn

  • Linear, radial and conic gradients with from-, via-, to-, and angles.
  • Background images, size and position.
  • Borders, divide-*, rounded-*, outlines and rings, and the difference between them.
  • Shadows: sizes, coloured shadows, inset shadows.
  • Opacity, blend modes, filters, backdrop-blur and masks.

Gradients

A gradient has a shape and colour stops. The shape is bg-linear-to-r (towards the right; also -t, -br…), an angle like bg-linear-45, bg-radial or bg-conic. The stops are from-*, an optional via-*, and to-*:

  • from-20%, to-80% move the stops.
  • The /oklch, /srgb, /hsl… modifier picks the colour space the gradient travels through. The default is OKLab, which avoids the muddy grey middle that sRGB gradients often have.
  • Radial: bg-radial-[at_25%_25%] from-white to-zinc-900. Conic: bg-conic from-sky-600 to-sky-400.

The plain to right is a fallback; browsers that support colour-space interpolation in gradients use to right in oklab. The stop utilities fill --tw-gradient-stops.

Borders and dividers

border is a 1 px solid border (Preflight sets the style to solid and the colour to the current text colour); border-2, border-4, border-x, border-t-2 set widths; border-slate-200 the colour; border-dashed, border-dotted the style. divide-y adds borders between children:

Rounded corners

rounded-xs (2 px), rounded-sm (4), rounded-md (6), rounded-lg (8), rounded-xl (12), rounded-2xl (16), rounded-3xl (24), rounded-4xl (32), rounded-full, rounded-none. Per side or corner: rounded-t-lg, rounded-br-xl, rounded-s-md (logical start). In v4, rounded alone is 4 px, the same as rounded-sm.

Outline vs ring

In v4, ring alone is 1 px and uses currentColor (in v3 it was 3 px and blue). For focus states, the docs recommend outline.

🧠 Analogy: a border is the frame of a picture: part of its size. A ring is a shadow painted to look like a frame: no space taken, but it disappears when shadows are turned off. An outline is a chalk line drawn around the picture: no space taken, and it's always drawn, which is why it's the safest focus indicator.

Shadows

shadow-2xs, shadow-xs, shadow-sm, shadow-md, shadow-lg, shadow-xl, shadow-2xl get progressively larger. Shadows take a colour and opacity (shadow-sky-500/40), and there are inset shadows:

v4 renamed the sizes: v3's shadow-sm is now shadow-xs, and v3's shadow is now shadow-sm. The same shift happened for rounded, blur and drop-shadow (Appendix A).

Opacity, blend modes and filters

  • opacity-50, opacity-0: the whole element, including children.
  • mix-blend-multiply, bg-blend-overlay: blend modes.
  • blur-sm, grayscale, brightness-110, contrast-125, sepia, drop-shadow-lg: filters on the element.
  • backdrop-blur-md, backdrop-brightness-75: filters on what's behind the element, for frosted glass.

Masks (v4.1)

Mask utilities fade parts of an element out: mask-b-from-50% fades the bottom half, mask-radial-from-40% fades from the centre outwards. They compose: mask-t-from-80% mask-b-from-80% fades both ends.

Recap

  • Gradients: shape (bg-linear-to-r, bg-linear-45, bg-radial, bg-conic) + from-/via-/to- stops; /oklch picks the interpolation space.
  • Images: bg-[url(…)] bg-cover bg-center.
  • border, divide-y, rounded-*; rounded = rounded-sm = 4 px in v4.
  • Outlines for focus; rings (box-shadow) for decorative borders; ring is 1 px in v4.
  • shadow-* with colour and opacity; inset-shadow-*; sizes shifted one step from v3.
  • opacity-*, filters (blur, grayscale), backdrop-blur, masks (mask-b-from-*).

Exercises

Exercise 1 🟢 easy gradient

Write a top-to-bottom gradient from white to sky-100.

Show solution

bg-linear-to-b from-white to-sky-100

Exercise 2 🟢 easy divide

A vertical list of settings rows should have a thin grey line between rows but not above the first or below the last.

Show solution

divide-y divide-slate-200 on the list.

Exercise 3 🟢 easy shadow

Give a primary button a soft glow in its own colour (indigo-600).

Show solution

bg-indigo-600 shadow-lg shadow-indigo-600/40

Exercise 4 🟢 easy pill

Make a fully rounded pill-shaped tag with a 1 px emerald border that doesn't change the tag's size.

Show solution

rounded-full ring-1 ring-emerald-500 px-2 py-0.5 (a ring takes no space; border would add 1 px on each side).

Exercise 5 🟡 medium focus

Why do the docs recommend outline rather than ring for focus indicators? Write a focus style for an input.

Show solution

Rings are box-shadows, which Windows high-contrast (forced colours) mode removes, so keyboard users would lose the indicator. Outlines are kept. focus:outline-2 focus:outline-offset-2 focus:outline-sky-500.

Exercise 6 🟡 medium upgrade

A v3 project has shadow, rounded and ring. What do they become in v4 to look the same?

Show solution

shadow-sm, rounded-sm, and ring-3 ring-blue-500 (v3's ring was 3 px blue; v4's is 1 px currentColor). The upgrade tool does this automatically (Appendix A).

Exercise 7 🟡 medium playground

In chapters/16/ build a sticky header with a frosted-glass effect over scrolling content.

Show solution

<header class="sticky top-0 z-10 bg-white/70 backdrop-blur-md border-b border-slate-900/10">. Add enough content below to scroll; the content blurs as it passes under the header.

Exercise 8 🟡 medium gradient text

Explain the three classes that make gradient text work. What happens if you forget text-transparent?

Show solution

A gradient background (bg-linear-to-r from-… to-…), bg-clip-text to clip the background to the glyph shapes, and text-transparent so the text colour doesn't cover it. Without the last one, you see solid-coloured text and no gradient.

Exercise 9 🔴 hard compose

An element has shadow-lg ring-2 ring-sky-500. Both use box-shadow. How can both appear at once?

Show solution

Each utility only sets its own variable (--tw-shadow, --tw-ring-shadow), and every one of them writes the same box-shadow declaration listing all five layers: inset shadow, inset ring, ring offset, ring, shadow. Unused layers are transparent (Chapter 5 showed this in the browser).

Exercise 10 🔴 hard mask

A horizontally scrolling list of logos should fade out at both left and right edges. Write the classes.

Show solution

overflow-x-auto mask-x-from-90% mask-x-to-100%, or with separate sides mask-l-from-90% mask-r-from-90%. The masks compose, so the content is fully visible in the middle and fades near each edge.
