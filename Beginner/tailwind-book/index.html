Tailwind CSS Study Book

Tailwind CSS is a utility-first CSS framework: you style pages by combining small classes like flex, pt-4 and text-center right in your HTML. This book teaches the current version, Tailwind CSS 4.3, chapter by chapter through the official docs: installation, the core concepts (states, responsive design, dark mode, theme variables, custom styles), and every utility group. It ends by installing Tailwind in a Next.js app the official way and building a complete landing page and dashboard.

How to use this book

  • Read in order. The 19 chapters follow the docs' sidebar: Getting Started, Core Concepts, then the utility groups, then a capstone. Each chapter only uses ideas from earlier ones, or says where an idea is explained.
  • Trust the outputs. Every example is a real file built with Tailwind CSS 4.3.5. Generated CSS blocks are copied from the real output, 🌐 browser blocks show values Chrome computed, terminal and error blocks were really run, and every 🖼 screenshot was taken by Chrome from the built page (at the width shown, with the mouse over or the field focused when the caption says so).
  • Look at the CSS. Tailwind is CSS. The book shows what each utility generates, so you learn the CSS property behind every class.
  • Do the exercises. Each chapter has 10 exercises marked 🟢 easy, 🟡 medium or 🔴 hard, with hidden solutions. Playground exercises are done in the practice project and lead to the capstone. 🧠 boxes give an everyday analogy for each hard idea.
  • Test yourself. The Final Assessment draws 50 random questions from a pool of 1000 and scores you per chapter.
  • Questions? The FAQ answers "why Tailwind instead of regular CSS?", "isn't this just inline styles?" and more; the Glossary defines every term.

💡 Comes after: the Next.js Study Book, whose capstone you'll recognise in Chapter 19. You need basic HTML and CSS (the box model, flexbox, selectors); React only matters for Chapter 19 and Appendix C. New here? Start with Using the Playground and Chapter 1.

🟩 Next step: the Node.js Study Book goes to the server side: modules, the event loop, streams, HTTP servers and testing.

📝 Setup: install Node.js 20 or newer (node --version), then clone the practice project, coderhop-learning/tailwindcss-playground, with git clone https://github.com/coderhop-learning/tailwindcss-playground.git, run npm install and npm run dev. It's a Vite project with one page per chapter, plus the finished capstone in reference/.

⚠️ Facts that change. Tailwind changed a lot in version 4 (January 2025) and keeps adding utilities in minor releases (text shadows and masks in 4.1, logical sizing and new colours in 4.2, scrollbars and @container-size in 4.3). Everything here was checked with Tailwind CSS 4.3.5 in November 2026. If you were sent to the v2 docs (v2.tailwindcss.com) or follow an older tutorial, read Appendix A: setup and several class names are different. Check the Tailwind blog for newer releases.
