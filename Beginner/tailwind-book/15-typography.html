Chapter 15 · Utilities in Depth

Typography

Text is most of what people read on a page, so the Typography group is large: font family, size, weight, line height, letter spacing, colour, decoration, wrapping, truncation, lists and number formatting. This chapter covers the utilities you'll use every week, shows the type scale with its built-in line heights, and adds a custom web font the v4 way.

You will learn

  • The type scale (text-xs … text-9xl) and its paired line heights, and the text-lg/7 shorthand.
  • Font family, weight, letter spacing (tracking-*) and line height (leading-*).
  • How to add a custom font with @font-face and --font-*.
  • Decoration, transforms, truncate, line-clamp-*, text-balance, text-pretty.
  • Lists, tabular-nums, antialiased and text shadows.

The type scale

Each text-* size sets font-size and a matching line-height, so text is readable without extra classes. Small sizes get roomier line heights; display sizes get a line height of 1:

To pick another line height in the same class, add a slash: text-lg/7 is 18 px text with a 1.75 rem (28 px) line height, text-sm/loose uses the named leading-loose. Or use leading-* separately:

Font family and custom fonts

There are three default families: font-sans (the system UI font, the page default), font-serif and font-mono. To add a web font, declare it with @font-face (or import it from a font service), then register it as a theme variable:

Put a remote @import url(…) before @import "tailwindcss": CSS requires @import rules to come first. To change the default font of the whole page, override --font-sans. For self-hosted fonts, write the @font-face rule in your CSS and keep the font files in your project.

🧠 Analogy: @font-face is buying the typeface and putting it in the drawer; --font-display in @theme is labelling the drawer so everyone can ask for it by name (font-display). Without the label the font is there but there's no class; without the font the label points to an empty drawer and the browser falls back to the next font in the list.

Lists and numbers

Preflight removes list bullets; bring them back with list-disc or list-decimal and some left padding (pl-5), or list-inside. For tables and prices, tabular-nums makes every digit the same width, so columns of numbers line up:

Each number feature has its own variable so you can combine them (tabular-nums slashed-zero). Since v4.2, font-features-["tnum","ss01"] sets any OpenType feature directly.

Exercises

Exercise 1 🟢 easy scale

What font size and line height does text-xl give? And text-xl/8?

Show solution

text-xl: 20 px with a 28 px line height (1.75 rem). text-xl/8: 20 px with 32 px (8 × 4 px).

Exercise 2 🟢 easy write

Style a price: 2 rem, extra bold, slate-900, digits aligned for a table.

Show solution

text-[2rem] font-extrabold text-slate-900 tabular-nums (or text-3xl, which is 1.875 rem, if close enough).

Exercise 3 🟢 easy bullets

Your <ul> has no bullets. Bring back round bullets with proper indentation.

Show solution

<ul class="list-disc pl-5">

Exercise 4 🟢 easy truncate

Show a product description in a card as at most three lines.

Show solution

line-clamp-3

Exercise 5 🟡 medium font

Make "Lora" (a serif from Google Fonts) the font for font-serif and "Inter" the default for the whole page.

Show solution

@import url("https://fonts.googleapis.com/css2?family=Inter&family=Lora&display=swap"); then @import "tailwindcss"; and @theme { --font-sans: "Inter", sans-serif; --font-serif: "Lora", serif; }.

Exercise 6 🟡 medium link

Style links in a paragraph: sky-700 text, a 1 px sky-300 underline 3 px below the text, which turns sky-700 and 2 px on hover.

Show solution

text-sky-700 underline decoration-sky-300 decoration-1 underline-offset-3 hover:decoration-sky-700 hover:decoration-2

Exercise 7 🟡 medium playground

In chapters/15/, set a heading's text with and without text-balance in a 300 px box. Describe the difference.

Show solution

Without it, the browser fills each line as much as possible and the last line may hold one word. With text-balance, the lines are roughly equal length, which looks better for headings. It's limited to short texts (a few lines) for performance.

Exercise 8 🟡 medium debug

A file name with truncate in a flex row overflows instead of showing "…". What's missing?

Show solution

min-w-0 on the flex item (or flex-1 min-w-0). Flex items don't shrink below their content's width by default, so there's never anything to truncate.

Exercise 9 🔴 hard order

You put @import url("https://fonts.googleapis.com/…") after @import "tailwindcss" and the font doesn't load. Why?

Show solution

In CSS, @import rules must come before all other rules. @import "tailwindcss" is replaced by Tailwind's whole stylesheet, so a later @import url(…) ends up after real rules, and browsers ignore it. Put remote imports first.

Exercise 10 🔴 hard design

Your design uses a 5-step type scale: 14, 16, 20, 28 and 40 px, each with its own line height, and nothing else. Configure the theme.

Show solution

@theme { --text-*: initial; --text-sm: 0.875rem; --text-sm--line-height: 1.5; --text-base: 1rem; --text-base--line-height: 1.6; --text-lg: 1.25rem; --text-lg--line-height: 1.5; --text-xl: 1.75rem; --text-xl--line-height: 1.3; --text-2xl: 2.5rem; --text-2xl--line-height: 1.1; }. The --text-NAME--line-height variables pair a line height with each size.
