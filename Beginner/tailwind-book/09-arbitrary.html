Arbitrary Values & Properties

The theme covers most needs, but sometimes a design needs an exact value: 117 pixels, a background image, a grid template. Square brackets let you put any value into a utility, any CSS property onto an element, and any selector into a variant, all without leaving your HTML. This chapter covers the bracket syntax from the docs' Adding custom styles page: arbitrary values, the CSS variable shorthand, type hints, arbitrary properties and arbitrary variants, and when to use them.

You will learn

  • Arbitrary values: top-[117px], bg-[#bada55], grid-cols-[200px_1fr].
  • How spaces and underscores work inside brackets.
  • The CSS variable shorthand bg-(--brand) and type hints.
  • Arbitrary properties: [mask-type:luminance], [--gap:2rem].
  • Arbitrary variants: [&.active]:, [&_p]:, [@supports(…)]:.
  • When to use them, and when to add a theme value instead.

Type hints for ambiguous utilities

Some prefixes map to more than one property. text- sets the font size and the colour: text-lg is a size, text-red-500 a colour. With a literal value Tailwind can tell (text-[22px] is a size, text-[#bada55] a colour), but a variable could be either. Give a hint:

Arbitrary variants

An arbitrary variant is a selector in brackets, where & stands for the element. It's like writing nested CSS inline, and Tailwind flattens it into a normal selector:

  • [&.is-active]: the element when it also has the class is-active (set by JavaScript).
  • [&_p]: every p inside it (the underscore is the descendant space).
  • [&>a]: direct child links.
  • [@supports(display:grid)]: an at-rule works too.

If you write the same arbitrary variant often, register it once with @custom-variant (Chapter 11) and give it a name.

When to use brackets

SituationDo
A one-off value that matches a design exactly (a hero image's offset)Arbitrary value: top-[117px]
The same value in several placesAdd it to @theme so it gets a name
A value from data at runtimeInline CSS variable + (--var) (Chapter 3)
A property Tailwind doesn't coverArbitrary property, or a custom utility (Chapter 11)
Styling elements you can't add classes toArbitrary variant [&_p]:, or the *: variant, or the Typography plugin (Appendix B)

⚠️ A codebase full of [13px], [#3a3a3a] and [0.37] has lost the main benefit of a design system. If a reviewer sees many brackets, the theme is probably missing something. tailwindcss canonicalize (Chapter 4) also rewrites brackets that match a theme value.

Recap

  • utility-[value] uses any value; Tailwind generates it on the fly and it works with variants.
  • Underscores stand for spaces; escape a real underscore with \_.
  • utility-(--var) is short for utility-[var(--var)].
  • Type hints (length:, color:…) resolve ambiguous prefixes like text-.
  • [property:value] sets any CSS property, including CSS variables.
  • [&…]: and [@…]: are arbitrary variants: any selector or at-rule.
  • Use brackets for one-offs; repeated values belong in the theme.

Exercises

Exercise 1 🟢 easy write

Write classes for: width exactly 342 px, a background of #1da1f2, and a font size of 15 px.

Show solution

w-[342px] bg-[#1da1f2] text-[15px]

Exercise 2 🟢 easy spaces

Write a grid template with columns 1fr 2fr 1fr as a class.

Show solution

grid grid-cols-[1fr_2fr_1fr]

Exercise 3 🟢 easy shorthand

Rewrite with the v4 shorthand: bg-[var(--brand)] and w-[var(--sidebar)].

Show solution

bg-(--brand) and w-(--sidebar).

Exercise 4 🟢 easy property

Tailwind has no utility for text-rendering: optimizeLegibility. Apply it to a heading with a class.

Show solution

<h1 class="[text-rendering:optimizeLegibility]">

Exercise 5 🟡 medium hint

You have style="--size: 1.5rem" and want it as a font size. Why doesn't text-(--size) work, and what's the fix?

Show solution

Without a hint, a variable after text- is treated as a colour, so it generates color: var(--size). Use text-(length:--size).

Exercise 6 🟡 medium variant

A JavaScript library adds the class is-dragging to a card while it's being dragged. Make the card get cursor-grabbing and a shadow-xl then.

Show solution

[&.is-dragging]:cursor-grabbing [&.is-dragging]:shadow-xl

Exercise 7 🟡 medium CMS content

A div receives HTML from a CMS. Style every link inside it sky-blue and underlined, and every h2 as text-xl font-bold, using classes on the div only.

Show solution

[&_a]:text-sky-700 [&_a]:underline [&_h2]:text-xl [&_h2]:font-bold. For long-form content, the Typography plugin (Appendix B) is usually better.

Exercise 8 🟡 medium playground

In chapters/09/, build a two-column layout where the sidebar is exactly 260 px and the content takes the rest, using one grid class. Then switch the sidebar width to a variable set at the lg breakpoint.

Show solution

grid grid-cols-[260px_1fr]; then grid grid-cols-[var(--side)_1fr] [--side:200px] lg:[--side:260px].

Exercise 9 🔴 hard review

A pull request contains p-[16px] mt-[24px] text-[#64748b] rounded-[8px] gap-[13px]. Write review comments: which should change and to what?

Show solution

p-[16px] → p-4, mt-[24px] → mt-6, text-[#64748b] → text-slate-500 (the v3 hex value of slate-500; check the design), rounded-[8px] → rounded-lg. gap-[13px] is off the 4 px scale: ask whether 12 px (gap-3) was intended; if 13 px is really needed in many places, add it to the theme.

Exercise 10 🔴 hard predict

Predict the CSS for md:[&:has(input:checked)]:bg-sky-50, then check it with the CLI.

Show solution

A @media (width >= 48rem) block containing .md\:\[\&\:has\(input\:checked\)\]\:bg-sky-50:has(input:checked) { background-color: var(--color-sky-50); }: the & is replaced by the class selector. (The built-in md:has-checked:bg-sky-50 is shorter and does nearly the same.)
