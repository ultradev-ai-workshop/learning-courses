Transitions, Transforms & Animation

Small, quick movement makes an interface feel responsive: a button that darkens smoothly, a card that lifts on hover, a spinner while something loads. This chapter covers the docs' Transitions & Animation and Transforms groups: transition with duration and easing, scale/rotate/translate (including 3D), the four built-in animations and custom ones, entry animations with starting:, and respecting users who prefer less motion.

You will learn

  • How transition, duration-*, ease-* and delay-* work together.
  • Transforms: scale-*, rotate-*, translate-*, skew-*, origin-*, and 3D.
  • animate-spin, animate-ping, animate-pulse, animate-bounce and custom animations.
  • Entry animations with starting: and transition-discrete.
  • motion-safe: and motion-reduce:.

Transitions

Without a transition, a hover style changes instantly. Add transition and the change is animated over 150 ms:

ClassWhat it transitions
transitionColours, opacity, shadows, transforms, filters (the common set)
transition-colorsOnly colours
transition-opacity, transition-shadow, transition-transformOne kind
transition-allEvery property (can be slow; use sparingly)
transition-noneNothing

duration-75 … duration-1000 (any number of ms), ease-linear, ease-in, ease-out, ease-in-out, and delay-* fine-tune it. Good defaults: 150–300 ms, ease-out for things appearing, ease-in for things leaving.

Transforms

In v4 each transform is its own CSS property (scale, rotate, translate), so they combine without a transform class:

Negative values use a leading dash (-rotate-6, -translate-x-1/2). Translate takes the spacing scale, fractions (-translate-x-1/2 to centre), full, and arbitrary values.

3D

perspective-* on a parent, transform-3d to keep children in 3D space, and rotate-x-*, rotate-y-*, translate-z-* on the children. backface-hidden hides the back of a flipped card:

🧠 Analogy: a transform is moving a sticker on a window: you can slide, turn or stretch the sticker, but the window (the layout) doesn't change. Neighbours don't move out of the way, which is why transforms are cheap to animate. Changing width or margin is rearranging the furniture: everything around it has to move too.

Animations

Four animations are built in:

  • animate-spin: a loading spinner.
  • animate-ping: a radar ripple, for notification dots.
  • animate-pulse: fades in and out, for skeleton placeholders while content loads.
  • animate-bounce: a "scroll down" hint.

Their @keyframes are only output when used. Custom animations go in @theme as --animate-* with their keyframes (Chapter 8 showed animate-fade-in); one-offs can use animate-[wiggle_1s_ease-in-out_infinite] with keyframes in your CSS.

Entry animations: starting:

CSS can now animate an element appearing (being added to the page, or going from display: none to visible) with @starting-style. Tailwind's starting: variant sets the values the element starts from:

When the popover opens, it starts 1 rem lower and transparent, then transitions to its normal place. transition-discrete (transition-behavior: allow-discrete) lets properties like display take part in the transition, so the element can also animate out.

Respecting reduced motion

Some people get dizzy or nauseous from movement and turn on "reduce motion" in their system settings. motion-reduce: and motion-safe: let you respond:

(The book's checker runs Chrome with "reduce motion" on, so the spinner stops.) A good habit: keep essential feedback (a colour change) for everyone and make big movement motion-safe:.

Recap

  • transition (+ duration-*, ease-*, delay-*) animates state changes like hover:.
  • scale-*, rotate-*, translate-*, skew-*, origin-*; each transform is independent in v4.
  • 3D: perspective-*, transform-3d, rotate-x-*, backface-hidden.
  • animate-spin/ping/pulse/bounce; custom ones as --animate-* with @keyframes in @theme.
  • starting: + transition-discrete for entry and exit animations.
  • Use motion-safe:/motion-reduce: to respect reduced-motion settings.

Exercises

Exercise 1 🟢 easy transition

A link changes colour on hover. Make the change smooth over 200 ms, colours only.

Show solution

transition-colors duration-200 hover:text-sky-700

Exercise 2 🟢 easy transform

Rotate a chevron icon 180° when its <details> parent is open.

Show solution

<details class="group"> and on the icon transition-transform group-open:rotate-180.

Exercise 3 🟢 easy spinner

Show a spinning loader inside a "Saving…" button.

Show solution

<button disabled class="inline-flex items-center gap-2"><svg class="size-4 animate-spin" …>…</svg>Saving…</button>

Exercise 4 🟢 easy centre

Centre an absolutely positioned element in its parent with translate.

Show solution

absolute top-1/2 left-1/2 -translate-x-1/2 -translate-y-1/2

Exercise 5 🟡 medium performance

Why is animating translate or scale smoother than animating margin-top or width?

Show solution

Transforms don't change the layout, so the browser can move the element's already-painted layer on the GPU (compositing). Changing margin or width forces a new layout and repaint of the element and its neighbours on every frame.

Exercise 6 🟡 medium reduced motion

Rewrite animate-bounce on a "scroll down" arrow so it only bounces for users who haven't asked for reduced motion.

Show solution

motion-safe:animate-bounce

Exercise 7 🟡 medium playground

In chapters/17/, build a notification dot with animate-ping on a bell icon, and make the bell wiggle on hover using a custom animation.

Show solution

Bell wrapper relative inline-block; dot as in the "Animations" example, placed with absolute -top-1 -right-1. Define --animate-wiggle as in "More examples" and add hover:animate-wiggle (or motion-safe:hover:animate-wiggle).

Exercise 8 🟡 medium easing

A dropdown appears with ease-in and feels sluggish. Which easing is better for appearing elements, and why?

Show solution

ease-out: it starts fast and slows down at the end, so the element responds immediately and settles gently. ease-in starts slow, which feels like a delay. Use ease-in for elements leaving.

Exercise 9 🔴 hard flip card

Build a card that flips over on hover to show a back side, using 3D utilities.

Show solution

Wrapper group perspective-normal; inner relative size-40 transition duration-500 transform-3d group-hover:rotate-y-180; front absolute inset-0 backface-hidden; back absolute inset-0 rotate-y-180 backface-hidden.

Exercise 10 🔴 hard entry

A <dialog> should fade and scale in from 95% when opened. Write the classes using starting:.

Show solution

<dialog class="transition-all transition-discrete duration-200 opacity-100 scale-100 starting:open:opacity-0 starting:open:scale-95">. The open: part targets the open state; starting: gives the values for the first frame.
