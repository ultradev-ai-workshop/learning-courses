Flexbox & Grid

Almost every layout on the web today is built with two CSS systems. Flexbox arranges items in one direction, a row or a column, and is ideal for toolbars, navigation and cards. Grid arranges items in rows and columns at once, and is ideal for page layouts and galleries. This chapter covers the utilities for both, which map almost one to one to the CSS properties, with screenshots of each layout.

You will learn

  • Flex containers: direction, wrapping, gap, and alignment with justify-* and items-*.
  • Flex items: flex-1, shrink-0, grow, basis-*, order-*.
  • Grid containers: grid-cols-*, grid-rows-*, grid-flow-*, auto-cols-*.
  • Grid items: col-span-*, col-start-*, row-span-*.
  • Subgrid, place-* shortcuts, and when to choose flex or grid.

Flexbox

Add flex to a container and its children line up in a row. A navigation bar in three classes: flex, items-center (vertical centring) and justify-between (push the groups to both ends):

🧠 Analogy: flexbox is books on a shelf. justify-* decides how the books spread along the shelf (bunched left, centred, spaced out); items-* decides how they line up top to bottom (tops aligned, bottoms aligned, centred). flex-col turns the shelf on its side, so "along" becomes "up and down".

Flex items: who grows, who shrinks

The most useful item classes are flex-1 ("take the remaining space, and share it equally"), shrink-0 ("never get smaller than your size") and flex-none ("don't grow or shrink"). A media object with a fixed avatar and text that fills the rest:

Grid

Add grid and say how many columns with grid-cols-*. Items flow into the cells, and gap-* spaces them:

grid-cols-3 is repeat(3, minmax(0, 1fr)): three equal columns that never overflow because of long content (that's what the minmax(0, …) is for). Any number works: grid-cols-7, grid-cols-16. For other templates use brackets: grid-cols-[200px_1fr], or grid-cols-subgrid (below).

Flex or grid?

Use flexbox when…Use grid when…
Items flow in one line (toolbar, nav, button group, tags)You need rows and columns that line up
Item sizes come from their contentThe layout defines the sizes (12-column page, gallery)
You want "push this to the end" (ml-auto, justify-between)Items span cells or overlap (col-span, row-start)

They combine freely: a grid of cards, each card a flex column.

Recap

  • flex + flex-col/flex-wrap + gap-* + justify-* (main axis) + items-* (cross axis).
  • Items: flex-1 fills space, shrink-0 protects a size, basis-* sets a start size, ml-auto pushes to the end.
  • grid grid-cols-N makes N equal columns (minmax(0, 1fr)); col-span-*/row-span-* span cells.
  • Custom templates with brackets: grid-cols-[8rem_1fr], repeat(auto-fill,minmax(…)).
  • grid-cols-subgrid/grid-rows-subgrid align nested content to the parent grid.
  • Flex for one-dimensional flows, grid for two-dimensional layouts; combine them.

Exercises

Exercise 1 🟢 easy centre

Centre a single child horizontally and vertically inside a 200 px tall box, with flexbox.

Show solution

flex h-50 items-center justify-center (or with grid: grid h-50 place-items-center).

Exercise 2 🟢 easy gallery

A gallery: 2 columns on phones, 3 from md, 4 from lg, with 1 rem gaps.

Show solution

grid grid-cols-2 gap-4 md:grid-cols-3 lg:grid-cols-4

Exercise 3 🟢 easy read

What does flex flex-col items-start gap-2 do to three buttons?

Show solution

Stacks them vertically with 0.5 rem between them, each as wide as its content and aligned to the left (instead of stretching to full width, which is the default items-stretch).

Exercise 4 🟢 easy span

In a 12-column grid, make the main content 8 columns and the sidebar 4.

Show solution

Container grid grid-cols-12 gap-6; main col-span-8; sidebar col-span-4.

Exercise 5 🟡 medium debug

In a flex row, a long URL in the text pushes the layout wider than the screen even though the text has flex-1. Why, and what's the fix?

Show solution

Flex items have min-width: auto by default, so they won't shrink below their longest unbreakable word. Add min-w-0 to the text item (and break-words or truncate to the text).

Exercise 6 🟡 medium order

On phones an image should appear above the text; from md the image should be on the right of the text. The HTML has the text first. Write the classes.

Show solution

Container flex flex-col md:flex-row; image order-first md:order-last (or use flex-col-reverse md:flex-row on the container). Remember that order changes only the visual order; keyboard and screen-reader order follow the HTML.

Exercise 7 🟡 medium playground

In chapters/13/ build the holy-grail layout, then make it responsive: below md the sidebar goes under the main content and everything is one column.

Show solution

Container grid grid-cols-1 md:grid-cols-[12rem_1fr]; header and footer md:col-span-full; sidebar order-last md:order-none (or place it with md:row-start-2 and keep it after main in the HTML).

Exercise 8 🟡 medium explain

Why does grid-cols-3 use minmax(0, 1fr) rather than just 1fr?

Show solution

1fr alone has a minimum of auto: a column won't get narrower than its widest content, so a long word or a wide image makes columns unequal or overflow. minmax(0, 1fr) lets columns shrink to 0, keeping them equal.

Exercise 9 🔴 hard bento

Build a 4×2 "bento" grid: one big tile spanning 2 columns and 2 rows on the left, and four small tiles filling the rest.

Show solution

Container grid grid-cols-4 grid-rows-2 gap-3; big tile col-span-2 row-span-2; four small tiles with no extra classes: auto-placement fills the remaining 2×2 cells.

Exercise 10 🔴 hard subgrid

Three product cards have an image, a title of varying length, and a button. Make all three buttons line up at the same height using subgrid.

Show solution

Parent grid grid-cols-3 gap-x-6 gap-y-2; each card row-span-3 grid grid-rows-subgrid, with image, title and button as its three children. The parent's rows size to the tallest title, so all buttons share the third row.
