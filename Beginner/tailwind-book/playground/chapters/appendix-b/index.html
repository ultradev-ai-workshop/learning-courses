Learning in public

Writing about what you learn is one of the fastest ways to understand it. You find the gaps in your knowledge the moment you try to explain something.

How to start

  1. Pick one small topic a week.
  2. Write what you tried, what failed and what worked.
  3. Publish it, even if it feels too simple.

The best time to write about something is right after you learned it.

Code snippets like npm run dev and links should look good too.
