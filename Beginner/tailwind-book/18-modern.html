Chapter 18 · Utilities in Depth

Container Queries & Modern CSS

Tailwind v4 was built on modern CSS, and each release adds utilities for new browser features. This chapter starts with container queries, which let components respond to the space they're given instead of the screen size, and then covers the interactivity utilities from the docs' sidebar and the newest additions: auto-growing text areas, scroll snapping, styled scrollbars and zoom (v4.3), and form-control styling with accent-* and appearance-none.

You will learn

  • Container queries: @container, @sm: … @7xl:, @max-*, named containers, arbitrary sizes.
  • Container query units and @container-size (v4.3).
  • Forms: accent-*, appearance-none, caret-*, field-sizing-content.
  • Scrolling: scroll-smooth, scroll snap, scroll-mt-*, and the v4.3 scrollbar utilities.
  • zoom-* and tab-* (v4.3), cursor-*, select-*, pointer-events-*.

Container queries

Mark an element with @container. Its descendants can then use @sm:, @md:, @lg:… which apply when the container is at least that wide, whatever the screen size:

Container sizes come from the --container-* theme variables, which are smaller than the screen breakpoints because components are smaller than screens:

🧠 Analogy: media queries ask "how big is the room?"; container queries ask "how big is my table?". A plate setting that adapts to the room would look silly on a small side table in a large hall. With container queries, each table lays out its own plates.

Ranges, names and arbitrary sizes

  • @max-md: applies below a container size; @sm:@max-md: targets a range.
  • @min-[475px]: and @max-[960px]: for one-off sizes.
  • Named containers: @container/main on an ancestor and @lg/main: on a descendant query that specific container, not the nearest one.

Container units and @container-size

Inside a container, the CSS units cqw (1% of the container's width) and cqh work in arbitrary values: text-[8cqw] scales text with its container. @container only tracks width (container-type: inline-size). New in v4.3, @container-size tracks both dimensions (container-type: size), so height queries and cqh/cqb units work. The container then needs an explicit height.

Scrolling

scroll-smooth on <html> animates jumps to #anchors. scroll-mt-20 on a heading leaves room for a sticky header when jumping to it. Scroll snap builds carousels with no JavaScript: snap-x snap-mandatory on the scroller, snap-center or snap-start on the items:

Each scrollbar colour utility sets its own variable and writes both into scrollbar-color, so thumb and track can be set separately. The last three classes are the new scrollbar utilities from v4.3: scrollbar-thin, scrollbar-auto, scrollbar-none set the width; scrollbar-thumb-* and scrollbar-track-* take any colour; scrollbar-gutter-stable reserves space so content doesn't jump when a scrollbar appears.

Recap

  • @container on a parent, @sm:…@7xl: on children: layouts follow the container's width.
  • @max-*, @min-[…], named containers (@container/main + @lg/main:), and cqw units.
  • @container-size (v4.3) queries both dimensions.
  • Forms: accent-*, appearance-none, caret-*, field-sizing-content.
  • Scrolling: scroll-smooth, scroll-mt-*, snap-*, and scrollbar-* (v4.3).
  • cursor-pointer, select-none, pointer-events-none, zoom-* and tab-*.

Exercises

Exercise 1 🟢 easy container

Make a card's content switch from a column to a row when the card's container is at least 28 rem wide.

Show solution

Parent @container; content flex flex-col @md:flex-row (@md = 28 rem).

Exercise 2 🟢 easy accent

Colour all checkboxes in a form with your brand colour violet-600.

Show solution

accent-color is inherited, so accent-violet-600 once on the <form> colours every checkbox, radio and slider inside it.

Exercise 3 🟢 easy anchors

Jumping to #faq hides the heading under a 64 px sticky header. Fix it.

Show solution

<h2 id="faq" class="scroll-mt-16"> (16 × 4 = 64 px; scroll-mt-20 leaves extra room).

Exercise 4 🟢 easy textarea

Make a comment box that grows with its content, starting at 3 lines high and never resizable by dragging.

Show solution

<textarea class="field-sizing-content min-h-[3lh] resize-none"> (lh is one line height; min-h-18 also works).

Exercise 5 🟡 medium named

A sidebar widget is inside a card (itself a container) inside the main layout (a named container layout). Hide the widget's chart when the layout is narrower than 48 rem.

Show solution

Layout: @container/layout. Chart: @max-3xl/layout:hidden (@3xl = 48 rem).

Exercise 6 🟡 medium carousel

Build a horizontally scrolling list of cards that always snaps so a card's left edge aligns with the list's left edge.

Show solution

List: flex snap-x snap-mandatory gap-4 overflow-x-auto; cards: w-64 shrink-0 snap-start.

Exercise 7 🟡 medium playground

In chapters/18/, put the same "profile card" in a 16 rem sidebar and in a 40 rem main column. Make it adapt with container queries only (no md:), with three layouts: stacked, row, and row with an extra "Follow" button from @lg.

Show solution

Wrap each card in @container; card flex flex-col @sm:flex-row @sm:items-center; button hidden @lg:block @lg:ml-auto. The sidebar copy stays stacked, the main copy shows the row with the button.

Exercise 8 🟡 medium zoom vs scale

You want a badge to look 25% bigger and push its neighbours away. Which class, scale-125 or zoom-125? Why?

Show solution

zoom-125: it changes the layout size, so neighbours move. scale-125 is a transform: it draws the badge bigger but keeps its original layout box, so it would overlap its neighbours.

Exercise 9 🔴 hard container units

A product card's title should be 7% of the card's width, but never smaller than 1 rem or larger than 2 rem. Write the class.

Show solution

Card @container; title text-[clamp(1rem,7cqw,2rem)].

Exercise 10 🔴 hard explain

Why does @container use container-type: inline-size and not size by default? What do you have to do differently with @container-size?

Show solution

With size, the container's height can't depend on its content (that would create a loop: content depends on container height, which depends on content). So size containers collapse to zero height unless you give them one. Width containers are what most layouts need. With @container-size you must set a height (h-40, h-dvh, a grid row…).
