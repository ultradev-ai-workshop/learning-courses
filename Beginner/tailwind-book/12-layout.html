Layout & Positioning

Part III goes through the utility groups in the docs' sidebar, starting with Layout: how an element is displayed, where it's positioned, how it stacks over others, what happens when content overflows, and how images and videos fit their boxes. Each section names the CSS property, so you can look up the details on MDN when you need them.

You will learn

  • Display utilities, including hidden, contents and sr-only.
  • Positioning with relative, absolute, fixed, sticky and the inset utilities.
  • Stacking with z-* and isolate.
  • Overflow, and scroll containers.
  • aspect-*, object-* and columns-*.

sr-only is the opposite of hidden: it hides content visually but keeps it for screen readers. Use it for labels on icon-only buttons:

not-sr-only undoes it, e.g. sr-only focus:not-sr-only for a "Skip to content" link that appears when focused with the keyboard.

Position

The position utilities are static, relative, absolute, fixed and sticky. Offsets use the spacing scale: top-0, -right-1, inset-0 (all four sides), inset-x-4 (left and right). The most common pattern is a badge on an avatar: the parent is relative, the badge absolute and placed in a corner.

🧠 Analogy: relative on the parent says "measure from me". An absolute child is a sticky note placed by measuring from the nearest such parent's edges: -top-1 -right-1 means "4 px above and 4 px beyond my top-right corner". Without a relative parent, it measures from the whole page.

Stacking: z-* and isolate

When positioned elements overlap, z-* sets the order: z-0, z-10 … z-50, any number (z-60), z-auto, or negative (-z-10). Higher is on top.

isolate creates a new stacking context, so the z-index values inside a component don't fight with the rest of the page. Put it on a card that uses -z-10 for a background decoration, and the decoration stays inside the card.

Overflow

overflow-hidden clips content; overflow-auto adds scrollbars only when needed; overflow-x-auto for horizontal scrolling only; overflow-scroll always shows them; overflow-clip clips without creating a scroll container. A wide table on a phone:

Related: overscroll-contain stops a scrolling panel from scrolling the page behind it when it reaches the end.

Images and video: aspect-* and object-*

aspect-video (16 / 9), aspect-square (1 / 1) or aspect-[4/3] give a box a fixed shape. object-cover makes an image fill the box, cropping what doesn't fit; object-contain shows all of it; object-top etc. choose which part to keep.

Columns

columns-2, columns-3 split text into newspaper-style columns; columns-3xs … columns-7xl set a column width instead, so the number of columns adapts to the space. Add break-inside-avoid to items that shouldn't be split across columns (a masonry-style card grid).

Recap

  • block, flex, grid, hidden, contents set display; sr-only hides visually but not from screen readers.
  • relative parent + absolute child + top/right/bottom/left/inset places things precisely.
  • sticky top-0 sticks within its scroll container; fixed pins to the viewport.
  • z-* orders overlapping elements; isolate keeps a component's stacking local.
  • overflow-hidden/auto/x-auto control clipping and scrolling.
  • aspect-* fixes a shape; object-cover/contain fits media inside it; columns-* makes text columns.

Exercises

Exercise 1 🟢 easy a11y

An icon button shows only a 🔍. Add text for screen readers without showing it.

Exercise 2 🟢 easy position

Place a "NEW" ribbon in the top-left corner of a product card, 8 px from each edge.

Show solution

Card: relative. Ribbon: absolute top-2 left-2.

Exercise 3 🟢 easy aspect

Make an embedded video always 16:9 and as wide as its container.

Show solution

<iframe class="aspect-video w-full" …>

Exercise 4 🟢 easy overlay

Write the classes for a dark overlay at 60% opacity that covers its relative parent completely.

Show solution

absolute inset-0 bg-black/60

Exercise 5 🟡 medium sticky

Your sticky top-0 header doesn't stick. Its parent has overflow-hidden. Explain and fix.

Show solution

A sticky element sticks within its nearest scroll container (any ancestor with overflow other than visible). overflow-hidden makes the parent that container, but it doesn't scroll, so nothing happens. Remove overflow-hidden, use overflow-clip (which doesn't create a scroll container), or move the header out.

Exercise 6 🟡 medium skip link

Write a "Skip to content" link that's invisible until it gets keyboard focus, then appears in the top-left corner.

Show solution

<a href="#main" class="sr-only focus:not-sr-only focus:fixed focus:top-2 focus:left-2 focus:z-50 focus:rounded focus:bg-white focus:px-3 focus:py-2">Skip to content</a>

Exercise 7 🟡 medium playground

In chapters/12/ build a hero image with a title on top: a 16:9 image with object-cover, a gradient overlay from transparent to black at the bottom, and white text at the bottom left.

Show solution

Wrapper relative aspect-video overflow-hidden rounded-xl; image absolute inset-0 size-full object-cover; overlay absolute inset-0 bg-linear-to-t from-black/70 to-transparent; text absolute bottom-4 left-4 text-2xl font-bold text-white.

Exercise 8 🟡 medium z-index

A dropdown (z-50) inside a card appears under the next card, which has relative z-10. The first card is also relative z-10. Why?

Show solution

The first card's z-10 creates a stacking context; the dropdown's z-50 only counts inside it. Between the two cards, equal z-10 means the later one in the HTML wins. Fix: remove z-10 from the cards, raise the open card (e.g. z-20 when its dropdown is open), or render the dropdown outside the card.

Exercise 9 🔴 hard contents

A list's <li> wrappers break your grid: each <li> contains an <a> that should be the grid item. Without changing the HTML structure, make the links the grid items.

Show solution

Put contents on each <li> (or *:contents on the <ul class="grid …">). The <li> boxes disappear and the links become direct grid items. Note: some browsers have had accessibility issues with display: contents on list items, so test with a screen reader.

Exercise 10 🔴 hard layout

Build a chat window: a fixed header, a message list that scrolls, and an input pinned at the bottom, all inside a box 400 px tall.

Show solution

Box: flex h-100 flex-col. Header: shrink-0. List: flex-1 overflow-y-auto overscroll-contain. Input bar: shrink-0. (Flexbox is Chapter 13; h-100 is 100 × 4 px = 400 px.)
