Reference

Glossary

The Tailwind CSS terms used in this book, in plain words, each with the chapter where it's explained.

@apply
Copies the declarations of utilities into your own CSS rule: .btn { @apply px-4 py-2; }. Use sparingly. Ch. 10
Arbitrary property
Any CSS declaration as a class: [mask-type:luminance], [--gap:2rem]. Ch. 9
Arbitrary value
Any value in square brackets after a utility name: top-[117px], bg-[#bada55]. Ch. 9
Arbitrary variant
A selector or at-rule in brackets used as a variant: [&.is-active]:font-bold. Ch. 9
Breakpoint
A minimum screen width where responsive variants start applying: sm 40rem, md 48rem, lg 64rem, xl 80rem, 2xl 96rem. Ch. 6
Cascade layers
The CSS @layer feature. Tailwind's output has theme, base, components and utilities layers; later layers win. Ch. 1
canonicalize
A CLI command that rewrites classes into their simplest form: w-12 h-12 → size-12. Ch. 4
CLI (@tailwindcss/cli)
The standalone command that turns an input CSS file into an output CSS file: npx @tailwindcss/cli -i in.css -o out.css. Ch. 2
Container query
A style that depends on a parent's width instead of the screen's: @container on the parent, @md: on children. Ch. 18
@custom-variant
Defines a new variant from a selector or at-rule, e.g. class-based dark mode. Ch. 11
Dark mode
The dark: variant; by default it follows prefers-color-scheme, or a class/attribute with @custom-variant. Ch. 7
Detection (source detection)
How Tailwind finds class names: it reads source files as plain text and generates CSS for tokens that match utilities. Ch. 11
group / group-*
Mark a parent with group to style children based on its state: group-hover:text-white. Ch. 5
IntelliSense
The official editor extension: autocomplete, hover previews and linting for classes. Ch. 4
Important modifier
A ! at the end of a class adds !important: bg-red-500!. Ch. 3
Mobile first
Unprefixed utilities apply at every size; breakpoint variants override them from that width up. Ch. 6
Modifier
The part after a slash: opacity in bg-sky-500/50, line height in text-lg/7, a group name in group-hover/item. Ch. 8
Namespace
The prefix of a theme variable that decides which utilities it creates: --color-*, --font-*, --breakpoint-*. Ch. 8
OKLCH
The colour space Tailwind's palette is defined in: lightness, chroma, hue. Steps in lightness look even. Ch. 8
peer / peer-*
Mark an element with peer to style its later siblings based on its state: peer-invalid:visible. Ch. 5
Play CDN
A script tag that runs Tailwind in the browser; for experiments, not production. Ch. 2
@plugin
Loads a JavaScript plugin such as Typography or Forms. App. B
PostCSS plugin (@tailwindcss/postcss)
Tailwind as a PostCSS plugin, for frameworks that run PostCSS, such as Next.js. Ch. 2
Preflight
Tailwind's reset in the base layer: no margins, unstyled headings and lists, border-box sizing. Ch. 3
prose
The Typography plugin's class that styles uncontrolled HTML such as Markdown output. App. B
@reference
Makes a stylesheet's theme and utilities known (for @apply) without outputting its CSS. Ch. 10
Ring
An outline drawn with box-shadow: ring-2 ring-sky-500. Takes no space. Ch. 16
Safelist
Classes generated even though they don't appear in your files: @source inline("…"). Ch. 11
Semantic colour
A colour named for its role (surface, ink) whose value changes per theme, registered with @theme inline. Ch. 7
@source
Adds paths to scan, excludes paths (not), or safelists classes (inline()). Ch. 11
Spacing scale
Spacing and sizing utilities are multiples of --spacing (0.25rem): p-4 = 1rem. Ch. 3
Subgrid
A nested grid that uses its parent's tracks: grid-cols-subgrid, grid-rows-subgrid. Ch. 13
@theme / theme variable
A CSS variable defined in @theme: a design token that also creates utilities. Ch. 8
Utility (utility class)
A small single-purpose class such as flex or pt-4, generated on demand. Ch. 1
@utility
Defines your own utility, simple or functional (name-* with --value()). Ch. 11
Variant
A prefix that applies a utility conditionally: hover:, md:, dark:, aria-pressed:. They stack: md:hover:. Ch. 5
Vite plugin (@tailwindcss/vite)
The recommended integration for Vite and frameworks built on it. Ch. 2
