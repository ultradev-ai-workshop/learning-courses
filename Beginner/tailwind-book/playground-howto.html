Using the Playground

The playground is where you practise. It's a small Vite project with Tailwind CSS installed the recommended way and one page per chapter, where you do the exercises marked playground. Its reference/ folder holds the finished capstone from Chapter 19, a Next.js app. This page shows how to get it, the everyday loop, and what to do when something goes wrong.

You will learn

  • What's in the tailwindcss-playground repository.
  • The one-time setup: Node.js, cloning, installing, editor extensions.
  • The everyday loop: npm run dev, edit a chapter page, npm run format.
  • How to run the reference solution.
  • Fixes for the problems beginners hit most often.

What is the playground?

The starter follows Chapter 2's Vite setup exactly. The only extra: src/style.css has @source not "../reference";, so the capstone's files aren't scanned for the chapter pages (Chapter 11 explains @source).

One-time setup

  1. Install Node.js 20 or newer (the LTS version from nodejs.org, or with a version manager such as nvm). Check it:
  1. Clone the repository and install its dependencies:
  1. Set up your editor: install the Tailwind CSS IntelliSense and Prettier extensions, and associate *.css with the "tailwindcss" language (Chapter 4).

📝 Prefer to start from scratch? Follow Chapter 2's Vite steps and create a chapters/ folder yourself. You'd miss the reference capstone, so clone the repository anyway.

The everyday loop

StepCommandWhy
1. Developnpm run devStarts Vite at localhost:5173. Open /chapters/05/ for Chapter 5. Saving a file updates the browser instantly.
2. InspectDevTools → Elements → Styles / ComputedSee which utility set which property, and the final values. Toggle :hover and other states in the Styles panel.
3. Formatnpm run formatPrettier sorts your classes in the standard order (Chapter 4).
4. Buildnpm run buildBuilds every page into dist/ with minified CSS. npm run preview serves it.

💡 Keep DevTools' device toolbar (Ctrl/Cmd+Shift+M in Chrome) open while you work on responsive chapters, and use its "prefers-color-scheme" emulation (Rendering panel) for dark mode.

Troubleshooting

ProblemCause and fix
A class does nothingTypo (no IntelliSense colour swatch?), or a class name built from pieces in JavaScript (Chapter 11). Check DevTools: is the rule in the stylesheet at all?
Headings and lists look like plain textThat's Preflight, not a bug: style them with utilities (Chapter 3), or use prose for articles (Appendix B).
Styles don't change when I saveIs npm run dev still running? Is the page loaded from localhost:5173 and not opened as a file? Reload once.
dark: classes don't react to the toggleThe page must use a stylesheet with @custom-variant dark … (Chapter 7 uses chapters/07/style.css). Without it, dark: follows the system setting.
hover: doesn't work on my phoneBy design: hover: only applies on devices that can hover (Chapter 5). Use active: or focus-visible: for touch feedback.
VS Code shows "Unknown at rule @theme"Associate *.css with "tailwindcss" (Chapter 4).
npm install fails or vite isn't foundNode.js is too old: install 20 or newer, delete node_modules, and run npm install again.
Port 5173 is busyVite picks the next free port automatically; read the address it prints.
Code from a tutorial doesn't workIt's probably v2 or v3 (@tailwind base, bg-opacity-50…): see Appendix A.
I can't clone the repositoryCheck the URL https://github.com/coderhop-learning/tailwindcss-playground.git, or download the ZIP from GitHub's "Code" button.
