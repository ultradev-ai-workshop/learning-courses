if statements

An if statement runs a block only when a condition is true. elif ("else if") checks another condition, and else catches everything left over. Python checks them top to bottom and runs only the first matching block.

  • Each condition line ends with a colon :.
  • No parentheses are needed around the condition: write if amount < 0:, not if (amount < 0) {.
  • Logical operators are words: and, or, not (not &&, ||, !).

☕ Java / 🟨 JS: Python has no switch. A chain of elif is the usual replacement, and for matching on shapes of data there is match (Chapter 4). There is no ternary ?: either; see the conditional expression below.

Truthiness

A condition does not have to be True or False. Python asks the object "are you true-ish?" These values count as false; everything else is true:

  • False, None
  • zero: 0, 0.0
  • empty containers: "", [], (), {}, set(), range(0)

The conditional expression (Python's ternary)

When you just need to pick one of two values, use X if condition else Y. It reads like English.

for statements

Python's for is a for-each loop. It walks over the items of any iterable: anything that can hand out its items one at a time, such as lists, strings and ranges. There is no for (i = 0; i < n; i++) form.

☕ Java: like for (String w : words). 🟨 JS: like for (const w of words). Python's in is JS's of, not JS's in.

Don't change a collection while you loop over it

Changing a list (or dict) while looping over it confuses the loop: items can be skipped. Loop over a copy, or build a new collection.

The range() function

When you need a sequence of numbers, use range(). Like slicing, it includes the start and excludes the stop.

CallNumbers produced
range(5)0, 1, 2, 3, 4
range(5, 10)5, 6, 7, 8, 9
range(0, 10, 3)0, 3, 6, 9
range(-10, -100, -30)-10, -40, -70
range(10, 0, -2)10, 8, 6, 4, 2
range(5, 2)(nothing: start is already past the stop)

range(10) does not build a list of ten numbers. It produces each number on demand ("lazily"), so range(1_000_000_000) uses almost no memory. Functions like list() and sum() accept any iterable and pull the numbers out.

else clauses on loops

This feature surprises everyone coming from Java or JS. A for or while loop can have an else block. It runs when the loop finishes without hitting break.

Think of it as "no break". It is perfect for searches: the else means "I looked everywhere and didn't find it".

Look carefully: the else is lined up with the inner for, not with the if. That is what makes it a loop-else.

How the loop endedDoes else run?
Ran through every item✅ yes
Iterable was empty (zero passes)✅ yes
break❌ no
return or an exception❌ no
continue (any number of times)✅ yes (continue doesn't end the loop)

💡 Tip: for a simple membership test, if "fun" not in categories: is even shorter. Save for…else for searches that also do work along the way.

pass statements

pass does nothing. You use it where Python's grammar needs a statement but you have nothing to write yet, for example an empty function or class while sketching.

You can also write ... (the Ellipsis object) as a placeholder body. Many people use it in stubs.

Recap

  • if / elif / else runs the first matching branch. Conditions use truthiness: empty and zero values are false.
  • a if cond else b is Python's ternary.
  • for x in iterable walks over items. Use enumerate() when you need indexes, and don't change a collection while looping over it.
  • range(start, stop, step) excludes the stop and is lazy.
  • break exits a loop, and continue skips to the next pass. A loop's else runs only if no break happened.
  • pass is a do-nothing placeholder.
