Why Python?

Python is a general-purpose language that is famous for being easy to read. Code often looks like pseudo-code. It is used for scripting, web back-ends, data science, automation, testing and teaching.

The language is named after the comedy group Monty Python, not the snake. That is why the docs use the words spam and eggs in their examples. This book uses them too, sometimes.

Three things make Python feel different from Java:

  • It is interpreted. You do not run a separate compile step. You type python3 app.py and it runs. (Python does compile to bytecode behind the scenes, covered in Chapter 8, but you never call a compiler yourself.)
  • It is dynamically typed. A variable is just a name for an object. You do not declare int x. The object has a type; the name does not.
  • Indentation is syntax. Blocks are marked by indenting, not by { }. There are no semicolons at line ends.

Starting the interpreter

The interpreter is the program that reads and runs Python code. You can use it in two ways.

1. Interactive mode (the REPL)

Type python3 with no file name. You get a prompt where you type one statement at a time and see the result right away. REPL means Read–Eval–Print Loop: it reads your line, evaluates it, prints the result, and loops.

The primary prompt >>> asks for a new statement. The secondary prompt ... appears when a statement continues onto more lines, such as an if block.

Notes on that session:

  • 2 + 2 is an expression. The REPL prints its value automatically. In a script, you would need print().
  • Assignment (=) prints nothing.
  • After the if line, the prompt changes to .... Press Enter on an empty line to finish the block.

To quit: type exit (or quit), or press Ctrl+D on macOS/Linux, or Ctrl+Z then Enter on Windows.

Passing arguments to a script

Words typed after the script name are command-line arguments. Python puts them in a list called sys.argv, inside the sys module. To use it you must import sys first. (Modules are covered in Chapter 8; for now, import just means "load this toolbox".)

☕ Java: in Java, args[0] is the first user argument. In Python, sys.argv[0] is the script name, and the user's first argument is sys.argv[1]. 🟨 Node: this is like process.argv.slice(1).

💡 Tip: all arguments arrive as strings. python3 add.py 2 3 gives you "2" and "3". Convert them with int() before doing maths. For real tools, the argparse module (Chapter 13) parses arguments for you.

Getting around in the REPL

The interactive prompt is the best place to experiment. Since Python 3.13 it has a modern editor built in:

  • Colours for prompts and tracebacks.
  • Multi-line editing: press ↑ to bring back a whole for block, not just one line.
  • F1 opens help, F2 shows your history, F3 enters paste mode (paste big blocks without the indentation getting mangled).
  • Tab completes names: type str.up then Tab to get str.upper.

Two built-in helpers you will use all the time:

help(len) shows the documentation for len, and dir("hi") lists everything you can do with a string. Try them in your own REPL; press q to leave the help viewer.

Source code encoding

A text file is stored as bytes. An encoding is the rule that turns those bytes back into characters. Python reads .py files as UTF-8 by default. UTF-8 can store every character: accents, Greek, emoji.

If a file is saved in another encoding, you can declare it with a special comment on the first or second line, for example # -*- coding: cp1252 -*-. You will rarely need this. Save your files as UTF-8 and skip the line.

📝 New in 3.15: Python now also uses UTF-8 by default when it reads and writes files with open(), no matter what your computer's locale is (PEP 686). Chapter 9 explains why you should still write encoding="utf-8".

Executable scripts and the shebang line

On macOS and Linux, you can run a script directly (./tool.py) instead of typing python3 tool.py. You need two things:

  1. A shebang line as the very first line. It tells the operating system which program runs the file.
  2. Permission to execute the file: chmod +x tool.py.

On Windows, the py launcher reads the shebang line too, and .py files are linked to Python by the installer.

The interactive startup file

If you always import the same modules when you open the REPL, you can automate it. Point the PYTHONSTARTUP environment variable at a Python file. Python runs that file each time an interactive session starts. Scripts ignore it.

There are also sitecustomize and usercustomize modules, which run at startup for every program, scripts included. They are for advanced setups, so you can ignore them for now.

Your first error message

Errors in Python are called exceptions (Chapter 10). When one is not handled, Python prints a traceback: the chain of calls that led to the error, with the cause on the last line. Always read a traceback from the bottom up.

The last line names the error type (TypeError) and explains it: you cannot glue a string and a number together. Fix it with str(6), a comma in print, or an f-string (Chapter 9).

Recap

  • Python is interpreted, dynamically typed, and uses indentation for blocks.
  • python3 opens the REPL (>>> and ... prompts). python3 file.py runs a script.
  • sys.argv is a list of strings. Item 0 is the script name.
  • The REPL echoes expression values. Scripts need print().
  • Source files are UTF-8 by default. A shebang plus chmod +x makes a script executable.
  • Read tracebacks from the bottom line up.

Exercise 4 🟢 easy explain why

A friend's script show.py does print(sys.argv[1]) and crashes with IndexError when run as python3 show.py. Why?

Show solution

With no extra words, sys.argv is ['show.py'], a list with one item, at index 0. There is no index 1, so Python raises IndexError. Check len(sys.argv) first, or use sys.argv[1:], which is just empty instead of crashing.

Exercise 6 🟡 medium predict the output

Show solution

The first prints 4 + 5 = 9. The second crashes with ValueError: invalid literal for int() with base 10: 'four', because int() can only convert strings of digits. Chapter 10 shows how to catch this error politely.

Exercise 8 🟡 medium fix the bug

This file was pasted from a website and fails with IndentationError. What is wrong, and what is the fix?

Show solution

In Python, indentation is the block. A line ending in : must be followed by at least one indented line. Use 4 spaces per level.
