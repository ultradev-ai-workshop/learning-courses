Numbers

The REPL works like a calculator. Type an expression and it shows the value. + - * / work as you expect, and parentheses group.

Python has two main number types:

  • int: whole numbers like 2, -7, 1_000_000 (underscores are allowed for readability). An int has no maximum size.
  • float: numbers with a fractional part, like 5.0 and 1.6. Like Java's double.

☕ Java / 🟨 JS: in Java, 17 / 3 is 5 (integer division). In Python it is 5.666…. Use // when you want Java's behaviour. There is no ++ or -- in Python: write x += 1. Unlike JS, int and float are different types.

⚠️ Pitfall: negatives round toward minus infinity. // rounds down, not toward zero. The sign of % follows the divisor. Java and JS do it the other way.

Precedence: ** binds tighter than unary minus

Variables and mixed types

= gives a value a name. Using a name that was never assigned is an error. Mixing int and float gives a float.

Handy built-ins: abs(-3) is 3, round(3.7) is 4, int(3.9) is 3 (it truncates toward zero), float("2.5") is 2.5. Python also has complex numbers (3+5j), and Decimal and Fraction types (Chapter 14).

Floating point: why 0.1 + 0.2 ≠ 0.3

Computers store floats in binary (base 2). Many decimal fractions, like 0.1, cannot be written exactly in binary. It is the same as 1/3 in decimal: 0.3333… never ends. So Python stores the closest binary number it can.

Analogy: you measure a table with a ruler marked only in 1/8 inches. Most lengths come out a tiny bit off. The errors are small, but they can add up.

✅ Compare with a tolerance

💡 Tip: for money, store whole cents as int (1999 instead of 19.99), or use decimal.Decimal (Chapter 14). This is the same advice as Java's BigDecimal, and it is not a Python bug. Every language that uses IEEE-754 floats behaves this way, JS and Java included.

Text (strings)

A string (str) is a sequence of characters. Use single quotes '…' or double quotes "…"; they mean the same thing. Pick whichever lets you avoid escaping.

The REPL shows a string's representation (with quotes). print() shows the text itself.

There is no separate char type: one character is just a string of length 1.

Raw strings and triple quotes

In a raw string (r"..."), backslashes are not special. That is useful for Windows paths and regular expressions (Chapter 13). Triple quotes ("""…""") let a string span several lines.

⚠️ Pitfall: an unknown escape like "\d" still works today, but Python prints SyntaxWarning: "\d" is an invalid escape sequence. A future version will make it an error. Use raw strings for regex patterns and Windows paths.

Indexing and slicing

Each character has an index (position) starting at 0. Negative indexes count from the end: -1 is the last character.

Think of the indexes as pointing between characters. The slice word[i:j] is everything between edge i and edge j. The start is included and the end is excluded.

Everyday string methods

A method is a function attached to an object, called with a dot: text.upper(). Methods never change the original string; they return a new one.

☕ Java / 🟨 JS: str.join is "backwards" compared with JS: you call it on the separator, as in ", ".join(items), while JS writes items.join(", "). Compare strings with ==; there is no .equals().

Lists

A list holds an ordered sequence of items in square brackets. It is like a Java ArrayList or a JS array. Items can be of any type, though usually they are all the same type.

Unlike strings, lists are mutable: you can change them in place.

Two names, one list (aliasing)

Assignment never copies. b = a makes b a second name for the same list. It is like two labels on one box. A slice, on the other hand, creates a new (shallow) copy.

☕ Java: this is exactly how object references behave in Java and JS. Python simply has no primitive types: every value, even 3, is an object, and every variable is a reference. Appendix A goes deeper.

Recap

  • / always gives a float. // floors, % follows the divisor's sign, and ** is power (it binds tighter than unary minus).
  • Floats are binary approximations: compare with math.isclose, and use integer cents or Decimal for money.
  • Strings are immutable sequences: index from 0 or from the end with negatives; slices include the start and exclude the end.
  • Lists are mutable. Assignment shares the list; lst[:] copies it.
  • a, b = b, a + b evaluates the right side first. while loops on a condition. print(..., sep=, end=) controls output.
