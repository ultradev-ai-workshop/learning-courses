Standard Library Tour I

Python comes with "batteries included": modules for files, command-line arguments, regular expressions, maths, dates, compression, timing and testing, all available without installing anything.

You will learn

  • Command-line tools: sys.argv, argparse, sys.stderr, sys.exit.

Operating system interface

The os module talks to the operating system: the current folder, environment variables, and file operations. Always write import os, not from os import *: os.open() would hide the built-in open(), which works quite differently.

💡 Tip: to run other programs, use the subprocess module (subprocess.run(["git", "status"])) rather than os.system(). It is safer and gives you the output and the exit code.

pathlib: the modern way to handle paths

pathlib.Path represents paths as objects. The / operator joins path parts, and many file operations are methods on the path.

File wildcards

glob finds files whose names match a wildcard pattern: * means any characters, ? means one character, and ** means any number of subfolders (with recursive=True).

Command-line arguments

You met sys.argv in Chapter 1. For real tools, argparse parses the arguments for you. It generates --help, checks types, and reports errors.

Running python3 top.py --help prints the usage and a description of every option, generated automatically.

Error output and program termination

sys has three standard streams: sys.stdin (input), sys.stdout (normal output) and sys.stderr (errors and warnings). Writing errors to stderr keeps them visible even when the normal output is redirected to a file (Appendix B).

String pattern matching

The re module provides regular expressions: a small language for describing text patterns. Always write patterns as raw strings (r"…"), so that backslashes reach re unchanged.

PatternMatches
\d / \w / \sa digit / a word character (letter, digit, _) / whitespace
.any character except a newline
* + ? {2,4}0 or more / 1 or more / 0 or 1 / 2 to 4 times
^ $ \bstart / end / a word boundary
[a-z], [^,]one character from a set / any character not in the set
( … ), (?P<name> … )a capture group / a named group

⚠️ Pitfall: re.match only matches at the start of the string. re.search looks anywhere, and re.fullmatch requires the whole string to match.

Mathematics

❌ Never use random for passwords or tokens. Its numbers are predictable. Use the secrets module instead: secrets.token_urlsafe(16).

Internet access

urllib.request fetches data from URLs, and smtplib sends email. (Most projects use the third-party requests or httpx package for HTTP; see Chapter 15.)

Dates and times

datetime supports date and time arithmetic and formatting. A date is a calendar day, a datetime is a date plus a time, and a timedelta is a duration.

💡 Tip: store dates as ISO strings ("2026-10-01") in JSON. They sort correctly as text, and fromisoformat() reads them back. For time zones, use zoneinfo.ZoneInfo("Europe/Berlin").

Data compression

zlib, gzip, bz2, lzma, zipfile and tarfile cover the common archive and compression formats.

Quality control

Good software comes with tests. Python ships two testing tools.

doctest: examples in docstrings that are checked

doctest finds REPL-style examples in your docstrings and checks that they still produce the output shown. This book's own examples are verified the same way.

unittest: full test suites

unittest is the xUnit-style framework, like JUnit. Write a class that subclasses TestCase, add methods whose names start with test, and use assert* methods.

☕ Java: unittest is JUnit. Most Python projects use the third-party pytest instead (installed with pip, Chapter 15), which lets you write plain assert statements in plain functions: def test_avg(): assert average([2, 4]) == 3.

Recap

  • os/shutil/glob/pathlib handle files. Prefer pathlib and subprocess in new code.
  • argparse builds real CLIs. Errors go to sys.stderr, and sys.exit(code) sets the exit code.
  • Use re with raw strings (match = at the start, search = anywhere, fullmatch = the whole string). Use math, random (not for secrets) and statistics for numbers.
  • datetime does date arithmetic and ISO formats. zlib compresses, and timeit/cProfile measure speed.
  • doctest checks examples and unittest is xUnit. csv, sqlite3, Counter and defaultdict come for free.

Exercise 8 🟡 medium explain why

Why should error messages go to sys.stderr, and why should a failing script call sys.exit(1)?

Show solution

When output is redirected (tool > out.txt) or piped into another program, stderr still reaches the user's screen and doesn't pollute the data. A non-zero exit code lets shells, scripts and CI systems detect the failure (if tool; then …). Appendix B covers both.
