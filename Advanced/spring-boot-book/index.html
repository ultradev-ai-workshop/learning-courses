🍃 Spring Boot Study Book

A chapter-by-chapter course through the official Spring Framework and Spring Boot reference documentation, from the IoC container to a tested, observable, deployable REST API. It's written for Java developers who know the language and want to understand how Spring really works — and a set of How-To guides covers the tasks you do every week.

How to use this book

  • Read in order. 20 chapters in six parts: Foundations (container, configuration, auto-configuration), Core Framework (validation, AOP, events), Web (MVC, errors, HTTP clients, WebFlux), Data (JDBC, JPA, transactions), Production (testing, security, observability, deployment) and a final project.
  • Use the How-To guides when you need to get something done: change the port, return Problem Details, add pagination, a second datasource, retries, JWT security, a Docker image… Each recipe is Problem → Solution → Code → Pitfalls.
  • Look for the 🧠 boxes. Every hard idea — proxies, the persistence context, transactions, the reactive model — comes with a real-world analogy; ☕ boxes connect it to what you know from plain Java and other frameworks.
  • Type the examples. Every example was compiled and run on Spring Boot 4.1.2 with Java 25, and its output checked. Most examples are a single main class that starts, prints and stops; test classes show their JUnit result. See Using the Playground.
  • Do the exercises. Each chapter has 10 exercises marked 🟢 easy, 🟡 medium or 🔴 hard, with hidden solutions. The playground exercises build towards the Library Loans API project.
  • Test yourself. The Final Assessment draws 50 random questions from a pool of 1000, and scores you per chapter.

💡 New to Java's modern features? Records, var, text blocks, sealed types, pattern matching and virtual threads appear throughout — Appendix A summarises them. Upgrading from Spring Boot 2 or 3? Appendix B lists everything that changed in Boot 4.

📝 Setup: install JDK 25 (17 is the minimum for Boot 4) and use the Maven wrapper in the playground, or create a project at start.spring.io. Check with java -version and ./mvnw -v.
