Using the Playground

The book comes with a ready-made Spring Boot project, playground/, published on GitHub as coder-hop/springboot-book-playground, where you can paste examples, do the exercises and grow the Library Loans project. This page shows how to set it up, how to run single examples and tests, and how the book's own examples are checked — so you know why your console may print a little more than the book does.

You will learn

  • What to install: a JDK, and (optionally) an IDE.
  • The playground's layout and its Maven wrapper.
  • How to run the application, a single example class, and tests.
  • How the book's examples were run, and the quiet defaults they use.
  • Fixes for the most common setup problems.

1. Install a JDK

Spring Boot 4 needs Java 17 or newer; the book uses Java 25 (an LTS release). Any distribution works — Eclipse Temurin, Amazon Corretto, Oracle, Microsoft. With SDKMAN!:

You don't need to install Maven: the playground has the Maven wrapper (mvnw), which downloads the right Maven version on first use. IntelliJ IDEA, VS Code (with the Extension Pack for Java and Spring Boot Extension Pack) and Eclipse all open Maven projects directly.

Everything under com.example.playground is component-scanned (Chapter 1). Put each exercise in its own sub-package — com.example.playground.ch03.ex5 — so beans from different exercises don't collide.

3. Running things

Most book examples are a single class with a main method that starts Spring, prints something and closes the context. In an IDE, open the class and click ▶ next to main. Examples that start a web server use port 0 (any free port) and call themselves with RestClient, so they never clash with an app already running on 8080.

4. How the book's examples are checked

A script (tools/check-snippets.mjs) builds one Maven project per page — with the starters listed for that page — compiles every example, runs each main class and each test class, and compares the output with the block shown below it in the book. To keep outputs short, it runs examples with these quiet defaults, which you can copy into application.properties if you want the same console:

Without them you'll see the Spring banner and INFO log lines — such as "Started SetupCheck in 1.1 seconds" — before the example's output. That's expected. A few platform-specific notices are also hidden (Netty's macOS DNS resolver message, Flyway's "H2 is newer than verified" warning); the chapters mention them where they appear. In expected output, ... stands for lines or text that differ between runs (ports, timings, generated ids).

💡 Shell blocks start with $: type the command, not the $. Lines below a command are its output. Java blocks show the file name in their header; the package line tells you where to put the file.

5. Common problems

SymptomFix
No playground/ folder on your machineClone it: git clone https://github.com/coder-hop/springboot-book-playground.git playground
release version 25 not supportedMaven runs with an older JDK. Set JAVA_HOME to the JDK 25 folder (./mvnw -v shows which one it uses).
Web server failed to start. Port 8080 was already in use.Another app (often an earlier run) holds the port. Stop it, or run with --server.port=8081 (or 0).
A bean or controller isn't found (404, NoSuchBeanDefinitionException)The class is outside the main class's package tree (Chapter 1) — move it under com.example.playground.
ConflictingBeanDefinitionException / "bean already defined"Two exercises declare classes with the same name in scanned packages. Use separate sub-packages and unique class names.
Flyway "checksum mismatch" after editing a migrationNever edit applied migrations (Chapter 13). In the playground's in-memory H2 database just restart; elsewhere add a new migration.
Tests can't find @WebMvcTest or @DataJpaTestBoot 4 moved them to per-technology test starters (spring-boot-starter-webmvc-test, -data-jpa-test); the playground's pom already has them.
Mockito prints "A Java agent has been loaded dynamically"Harmless on Java 21+; the pom passes -XX:+EnableDynamicAgentLoading to tests to silence it.
