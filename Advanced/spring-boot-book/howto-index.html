How-To Guides

43 recipes for the tasks Spring Boot developers do most often. Each one states the problem, gives a solution you can copy (run and checked like every example in this book), and lists the pitfalls. The chapters explain the why; these pages get things done.

💡 How to read a recipe: Problem (the situation) → Solution (configuration and code, with real output) → Pitfalls (what goes wrong in production). The tags link each recipe to the chapter with the background.

⚙️ H1 · Application & Configuration

H1 · server.port · context path

Change the port and context path

The app must run on port 9090 under /library, behind a reverse proxy that sets X-Forwarded-* headers.
H1 · profiles · profile groups

Set up dev / test / prod configuration

Local development uses H2 and verbose logging, production uses PostgreSQL and JSON logs. One jar must serve both.
H1 · environment variables · configtree

Keep secrets out of the repository

The database password and an API key must not be in application.yml or in git, but the app needs them at startup.
H1 · ApplicationRunner · ApplicationReadyEvent

Run code when the application starts

You need to warm a cache, check a connection or print a summary once the application is up.
H1 · @ConfigurationProperties · records

Add your own typed, validated settings

Your feature needs a URL, a timeout and a list of allowed countries — with sensible defaults, and a clear error if someone misconfigures them.
H1 · spring.config.import · config locations

Load an extra configuration file

Operations wants to drop a library-overrides.properties next to the jar that overrides a few settings, without rebuilding.
H1 · embedded server · starters

Switch from Tomcat to Jetty

Your organisation standardises on Jetty, or you want to compare servers.
H1 · Environment · /actuator/env

Find out where a property's value comes from

A setting has a value nobody expects. Is it the YAML file, an environment variable, a profile document?

🌐 H2 · Web & REST

H2 · ProblemDetail · @RestControllerAdvice

Return consistent errors for the whole API

Some endpoints return Boot's default error JSON, others plain strings, others stack traces. Clients want one shape.
H2 · Pageable · Spring Data web support

Paginate and sort a list endpoint

GET /books returns 50 000 rows. Clients need ?page=2&size=20&sort=title,desc, with limits.
H2 · MultipartFile · Resource

Upload and download files

Users upload a cover image for a book and download it later with the right content type and a file name.
H2 · OncePerRequestFilter · MDC

Log every request with its duration

Operations wants one log line per request: method, path, status and time — including 404s.
H2 · spring.jackson.* · Jackson 3

Adjust JSON output (dates, nulls, naming)

The frontend wants snake_case, no null fields and dates without time; one field needs a custom format.
H2 · CORS · Chapters 10, 17

Let a browser frontend call the API (CORS)

The React app on https://app.example.com (and http://localhost:5173 in development) gets CORS errors.
H2 · API versioning · Spring 7

Version the API in the URL path

You need /api/v1/… and /api/v2/… side by side, without copying every controller.

🗄️ H3 · Data Access

H3 · Flyway · baseline

Add Flyway to an existing database

Production already has tables created by hand years ago. You want versioned migrations from now on, without re-running the original DDL.
H3 · Flyway locations · profiles

Load seed data only in development

Developers want 50 sample books on startup; production must never get them.
H3 · DataSource · @Qualifier

Use two datasources

The main database is your own; reports must also be read from a legacy database.
H3 · @Version · ETag

Prevent lost updates over HTTP (ETag / If-Match)

Two librarians edit the same book in their browsers; the second save silently overwrites the first.
H3 · @SoftDelete · Hibernate 7

Soft-delete rows

Deleted members must disappear from the app but stay in the database for auditing.
H3 · projections · DTO

Read only the columns you need

A list screen shows title and author name for 10 000 books; loading full entities (and their relations) is slow.
H3 · logging · Hibernate

See the SQL and its parameters

A query is slow or wrong and you want to see exactly what Hibernate sends.

🔌 H4 · Integration & Background Work

H4 · timeouts · @Retryable

Call a slow, flaky API safely

A partner's currency API sometimes answers in 10 seconds and sometimes returns 503. Your endpoint must stay fast.
H4 · ClientHttpRequestInterceptor · RestClientCustomizer

Add a token to every outgoing request

Every call to the partner API needs Authorization: Bearer …, and the token expires every hour.
H4 · @Scheduled · cron

Run a job every night

Overdue reminders must go out at 02:30 Paris time, once — even with three instances running.
H4 · JavaMailSender · spring-boot-starter-mail

Send an e-mail

Members get a confirmation e-mail when they borrow a book.
H4 · @Cacheable · Caffeine

Cache a lookup with expiry and a size limit

Book details from a remote catalogue rarely change; you want them cached for 10 minutes, at most 10 000 entries.
H4 · @Async · 202

Start long work and return 202 Accepted

Generating a yearly report takes a minute. The HTTP request shouldn't hang for that long.

🔐 H5 · Security

H5 · SecurityFilterChain · EndpointRequest

Open some endpoints, protect the rest

Health checks, the API docs and GET /api/books must be public; everything else needs a login; admin endpoints need a role.
H5 · resource server · JWT

Accept tokens from Keycloak, Auth0 or Entra ID

Users log in at your identity provider; the API receives access tokens and must map the provider's role claim to Spring roles.
H5 · @PreAuthorize · bean references in SpEL

Let users access only their own data

GET /api/members/{id}/loans must work for that member and for librarians, nobody else.
H5 · DelegatingPasswordEncoder · UserDetailsPasswordService

Store passwords and upgrade old hashes

Legacy users have SHA-256 hashes; new ones should get BCrypt — and old hashes should be upgraded as users log in.
H5 · CORS · preflight

Enable CORS with Spring Security

After adding Spring Security, the browser app's requests fail CORS preflights with 401.
H5 · SecurityContextHolder · @AuthenticationPrincipal

Get the current user anywhere

The service layer needs the logged-in user's name to stamp "created by" — without passing it through every method.
H5 · @WithMockUser · httpBasic()

Test secured endpoints

You want proof that the rules hold — including that anonymous and unauthorised calls are rejected.

🚀 H6 · Testing & Operations

H6 · @WebMvcTest · MockMvcTester

Test a controller without starting the app

Full @SpringBootTests take seconds each; you want many fast tests for a controller's mapping, JSON and status codes.
H6 · Testcontainers · @ServiceConnection

Test against a real PostgreSQL

Your repository uses PostgreSQL features (JSONB, ON CONFLICT) that H2 doesn't have.
H6 · HealthIndicator · readiness

Add a health check for a dependency

The app depends on a search service; operations want to see its state in /actuator/health — without restarting pods when it's down.
H6 · Micrometer · Counter

Count business events

Product wants a dashboard of registrations per channel; operations want an alert when sign-ups drop to zero.
H6 · virtual threads · Java 21+

Handle requests on virtual threads

The service spends most of its time waiting for other services and the database; Tomcat's 200 threads are the bottleneck.
H6 · graceful shutdown · Kubernetes

Shut down without dropping requests

During deployments, a few requests fail with connection errors each time a pod is replaced.
H6 · buildpacks · layers

Build a container image

You need a small, secure image of the application for Kubernetes, without writing and maintaining a Dockerfile.
H6 · GraalVM · AOT

Build a native executable

A small service must start in milliseconds and use little memory (scale to zero, CLI tool, serverless).
